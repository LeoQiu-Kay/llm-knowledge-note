# 主流开源模型对比

> LLaMA / Qwen / DeepSeek 等主流模型的架构选择差异。

---

## Q1: LLaMA 1 / 2 / 3 的关键差异？

**答**：

| 维度 | LLaMA-1 | LLaMA-2 | LLaMA-3 |
|------|---------|---------|---------|
| 发布 | 2023.02 | 2023.07 | 2024.04 / 2024.07 |
| 训练数据 | 1.4T tokens | 2T tokens | 15T tokens |
| 序列长度 | 2K | 4K | 8K（可扩到 128K） |
| 词表 | 32K SP | 32K SP | 128K (TikToken-like) |
| 注意力 | MHA | GQA (70B 用) | GQA (8B/70B 全用) |
| 位置编码 | RoPE | RoPE | RoPE（base 调大） |
| 归一化 | RMSNorm | RMSNorm | RMSNorm |
| 激活 | SwiGLU | SwiGLU | SwiGLU |
| 规模 | 7/13/33/65B | 7/13/70B | 8/70/405B |
| Chat 版本 | ❌ | ✅ Llama-2-Chat | ✅ Llama-3-Instruct |

**LLaMA 系列共同特点**（事实上是当代 LLM 模板）：
- Decoder-only
- Pre-RMSNorm
- RoPE
- SwiGLU FFN
- 无 bias 项

**LLaMA-3 的关键升级**：
- 词表扩大 4× → 中文等多语种效率显著提升
- 训练数据 7.5× → 远超 Chinchilla 最优（追求推理效率）
- 8B 模型用 GQA（之前只 70B 用）

## Q2: Qwen 系列的演进？

**答**：

| 模型 | 关键特点 |
|------|---------|
| Qwen-1 | 类 LLaMA 架构，152K 词表（中文友好） |
| Qwen-2 | GQA、RMSNorm、SwiGLU；128K 上下文（YaRN） |
| Qwen-2.5 | 数据 18T tokens，强数学/代码版本 |
| Qwen-3 | 0.6B-235B 全尺寸，MoE 235B-A22B；Thinking 模式 |
| Qwen-VL / Qwen2-VL | 多模态版本 |

**Qwen 的国产特点**：
- 中文优化（词表、数据）
- 多语种支持广泛
- 开源最完整（多尺寸 + 多模态 + Chat/Base）

## Q3: DeepSeek 系列的演进？

**答**：

| 模型 | 创新点 |
|------|--------|
| DeepSeek-LLM | LLaMA-like 起步 |
| DeepSeek-V2 | **MLA**（Multi-head Latent Attention） + MoE |
| DeepSeek-V3 | MLA + DeepSeek-MoE（256 专家，8 激活） + **FP8 训练** |
| DeepSeek-R1 | 在 V3 基础上做大规模 RL（GRPO + 规则奖励） |
| DeepSeek-V3.1 / R1-0528 | 持续迭代 |

**DeepSeek 的标志性贡献**：
1. **MLA**：低秩压缩 KV，KV Cache 比 GQA 还小
2. **MoE 细粒度专家**：共享专家 + 路由专家
3. **FP8 训练**：大规模生产实践（V3 全量 FP8 训练）
4. **GRPO**：简化 PPO，去掉 Critic
5. **R1-Zero**：纯 RL 触发推理涌现

## Q4: Mistral / Mixtral 系列？

**答**：

**Mistral 7B**：
- **SWA**（Sliding Window Attention）：每个 token 只看前 4K
- **GQA**
- 性能远超同尺寸 LLaMA-2

**Mixtral 8×7B / 8×22B**：
- **首个开源高质量 MoE**
- 8 个专家，每 token 激活 2 个
- 总参数 47B，激活 13B
- 性能匹敌 GPT-3.5

**Mistral Large / Small**：闭源系列。

## Q9: 各家模型的核心选择差异？

**答**：

**注意力机制**：
- MHA：早期模型（LLaMA-1）
- MQA：少（Falcon、PaLM）
- **GQA**：LLaMA-2/3、Qwen-2/3、Mistral——**最主流**
- **MLA**：DeepSeek 独家

**MoE**：
- Mixtral、DeepSeek-V3、Qwen-3-MoE、GLM-4.5、Kimi K2

**长上下文**：
- Llama-3 (128K)、Qwen-2.5 (128K)、Gemini 1.5 (1M)、Kimi (200K)、Claude (200K)

**激活函数**：
- 几乎全用 SwiGLU

**归一化**：
- 几乎全用 RMSNorm
- 极个别用 LayerNorm

**位置编码**：
- 几乎全用 RoPE
- ALiBi 在 MPT、BLOOM
- 长上下文用 YaRN/NTK 扩展 RoPE

## Q10: 模型选择的实际考量？

**答**：
**开源 vs 闭源**：
- 闭源（GPT-4、Claude、Gemini）：能力强、API 易用、不可微调
- 开源（LLaMA、Qwen、DeepSeek）：可私有部署、可微调、需自维护

**推理成本 vs 能力**：
- 大模型（70B+）能力强但贵
- 小模型（7B-13B）便宜但弱
- MoE 折中（激活小、能力强）

**中文 vs 英文**：
- 中文：Qwen、DeepSeek、GLM 表现好
- 英文：LLaMA、Claude、GPT 表现好

**长上下文**：
- 100K-200K：多家可用
- 1M+：仅 Gemini 1.5 / Kimi 等少数

## 🎯 高频追问

1. **为什么 LLaMA-3 词表扩到 128K**？提升非英语效率（中文等），同时增加表达粒度。
2. **MLA 比 GQA 强多少**？KV Cache 更小，且效果略好（DeepSeek-V2 论文实验）。
3. **MoE 何时更优**？大规模训练 + 推理时单 token 激活参数少，但显存大；适合云端，不适合边缘。
4. **国产模型在追赶 GPT-4 吗**？DeepSeek-V3 / R1、Qwen-2.5 等已在多项基准接近或超越 GPT-4。
5. **小模型还有未来吗**？有，蒸馏 + 边缘部署 + Agent 场景小模型很有价值。
