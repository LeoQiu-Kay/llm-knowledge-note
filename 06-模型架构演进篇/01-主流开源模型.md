# 主流开源模型对比

> LLaMA / Qwen / DeepSeek / Mistral 等主流模型的架构选择差异。

---

## 1. LLaMA 系列演进

| 维度 | LLaMA-1 | LLaMA-2 | LLaMA-3 |
|---|---|---|---|
| 发布 | 2023.02 | 2023.07 | 2024.04 / 07 |
| 训练数据 | 1.4T tokens | 2T tokens | **15T tokens** |
| 序列长度 | 2K | 4K | 8K（可扩到 128K） |
| 词表 | 32K SP | 32K SP | **128K**（TikToken-like） |
| 注意力 | MHA | GQA（仅 70B） | **GQA**（全部） |
| 位置编码 | RoPE | RoPE | RoPE（base 调大） |
| 归一化 | RMSNorm | RMSNorm | RMSNorm |
| 激活 | SwiGLU | SwiGLU | SwiGLU |
| 规模 | 7/13/33/65B | 7/13/70B | 8/70/405B |

**LLaMA 系列的共同模板**（事实上是当代 LLM 默认）：
- Decoder-only
- Pre-RMSNorm
- RoPE
- SwiGLU FFN
- 无 bias 项

**LLaMA-3 的关键升级**：
- 词表 4× → 中文等多语种效率显著提升
- 数据 7.5× → 远超 Chinchilla 最优（追求推理效率）
- 8B 模型也用 GQA（之前只 70B 用）

## 2. Qwen 系列演进

| 模型 | 关键特点 |
|---|---|
| Qwen-1 | 类 LLaMA，152K 词表（中文友好） |
| Qwen-2 | GQA、RMSNorm、SwiGLU；128K 上下文（YaRN） |
| Qwen-2.5 | 训练数据 18T tokens，强数学/代码版本 |
| **Qwen-3** | 0.6B-235B 全尺寸 / MoE 235B-A22B / Thinking 模式 |
| Qwen-VL / Qwen2-VL | 多模态版本 |

**Qwen 特点**：
- 中文优化（词表、数据）
- 多语种支持广泛
- 开源最完整（多尺寸 + 多模态 + Chat/Base）

## 3. DeepSeek 系列演进

| 模型 | 创新点 |
|---|---|
| DeepSeek-LLM | LLaMA-like 起步 |
| **DeepSeek-V2** | **MLA**（Multi-head Latent Attention）+ MoE |
| **DeepSeek-V3** | MLA + DeepSeek-MoE（256 专家、8 激活）+ **FP8 训练** |
| **DeepSeek-R1** | V3 基础上做大规模 RL（GRPO + 规则奖励） |
| V3.1 / R1-0528 | 持续迭代 |

**DeepSeek 的标志性贡献**：
1. **MLA**：低秩压缩 KV，比 GQA 还小
2. **MoE 细粒度专家**：共享专家 + 路由专家
3. **FP8 训练**：大规模生产实践
4. **GRPO**：简化 PPO，去掉 Critic
5. **R1-Zero**：纯 RL 触发推理涌现

## 4. Mistral / Mixtral

**Mistral 7B**：
- **SWA**（Sliding Window Attention）：每个 token 只看前 4K
- **GQA**
- 性能远超同尺寸 LLaMA-2

**Mixtral 8×7B / 8×22B**：
- **首个开源高质量 MoE**
- 8 个专家，每 token 激活 2 个
- 总参数 47B，激活 13B

**Mistral Large / Small**：闭源系列。

## 9. 各家核心选择差异

**注意力机制**：
- MHA：早期模型（LLaMA-1）
- MQA：少（Falcon、PaLM）
- **GQA**：LLaMA-2/3、Qwen-2/3、Mistral——**最主流**
- **MLA**：DeepSeek 独家

**MoE**：Mixtral、DeepSeek-V3、Qwen-3-MoE、GLM-4.5、Kimi K2。

**长上下文**：LLaMA-3 (128K)、Qwen-2.5 (128K)、Gemini 1.5 (1M)、Kimi (200K)、Claude (200K)。

**激活函数**：几乎全用 SwiGLU。

**归一化**：几乎全用 RMSNorm。

**位置编码**：几乎全用 RoPE；ALiBi 在 MPT、BLOOM；长上下文 YaRN/NTK 扩展。

---

## 10. 模型选择的实际考量

**开源 vs 闭源**：
- 闭源（GPT-4、Claude、Gemini）：能力强、API 易用、不可微调
- 开源（LLaMA、Qwen、DeepSeek）：可私有部署、可微调

**推理成本 vs 能力**：
- 大模型（70B+）能力强但贵
- 小模型（7-13B）便宜但弱
- MoE 折中（激活小、能力强）

**中文 vs 英文**：
- 中文：Qwen、DeepSeek、GLM
- 英文：LLaMA、Claude、GPT

## 11. 最简记忆

```text
当代 LLM 默认模板：
  Decoder-only + Pre-RMSNorm + RoPE + SwiGLU + GQA

LLaMA 系列定义了模板，所有人在它上面改。

Qwen：中文 + 多尺寸 + 多模态最完整
DeepSeek：MLA + MoE + FP8 训练 + R1 推理路线
Mistral：SWA + Mixtral MoE
GPT / Claude / Gemini：闭源、能力顶尖
```

## 🎯 高频追问

1. **LLaMA-3 词表为什么扩到 128K**？提升非英语效率（中文等），同时增加表达粒度。

2. **MLA 比 GQA 强多少**？KV Cache 更小，效果略好（DeepSeek-V2 论文）。

3. **MoE 何时更优**？大规模训练 + 推理时单 token 激活参数少；适合云端、不适合边缘。

4. **国产模型在追赶 GPT-4 吗**？DeepSeek-V3 / R1、Qwen-2.5 等已在多项基准接近或超越 GPT-4。

5. **小模型还有未来吗**？蒸馏 + 边缘部署 + Agent 场景小模型很有价值。
