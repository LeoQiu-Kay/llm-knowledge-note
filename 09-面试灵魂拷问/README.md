## 🎯 答题方法论

### 1. 结构化回答（必做）

任何开放题都按 **5 步框架** 答：

```text
是什么 → 为什么需要 → 怎么做 → 效果 → 局限
（1-2 句）   （动机）    （核心机制）（数据）（什么时候不该用）
```

### 2. 涉及术语先解释

面试官的同事不一定都是你的同事——遇到 MHA/MQA/GQA/MLA 这种缩写，**先用一句话说清是什么**再展开。

### 3. 多角度展开

- **技术维度**：原理、公式、推导
- **工程维度**：显存、延迟、吞吐
- **业务维度**：什么场景下用

### 4. 主动给数字

"显著减少" → 不可信；"减少 8 倍 KV Cache"→ 立刻显专业。

### 5. 承认局限

"这个我不确定，但我的理解是..." 远好过"我胡编一个看起来对的"。

### 6. 反问澄清

"您们的场景是 X 还是 Y？" → 显示对实际问题的关注，而不是背诵。
