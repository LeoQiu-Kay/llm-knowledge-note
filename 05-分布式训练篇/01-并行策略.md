# 并行策略（DP / TP / PP / SP / EP）

> 训练 LLM 必须懂的并行方法，3D 并行是工业标准。

---

## 1. 朴素数据并行（DP）

**思想**：每张卡持有完整模型，处理不同数据，反向后 **AllReduce** 同步梯度。

**符号说明**：
- **DP**：Data Parallel
- **AllReduce**：集合通信原语，所有进程的 tensor 加起来后所有进程都得到结果

**问题**：
- 模型必须放得下单卡（大模型不行）
- 每步通信全部梯度（巨大）

**PyTorch DDP**：
- 反向同时进行 AllReduce（计算 / 通信重叠）
- 桶（bucket）合并小 tensor 减少通信次数

**适用规模**：小模型（< 单卡显存）。

---

## 2. ZeRO：把模型状态切到多卡

**ZeRO**（Zero Redundancy Optimizer，DeepSpeed）核心：DP 中每张卡持有完整模型状态有大量冗余。ZeRO 把模型状态切分到多卡。

### 2.1 模型状态构成（FP16 训练 + Adam）

| 项 | 大小 |
|---|---|
| 参数（FP16） | $2 \Psi$ bytes |
| 梯度（FP16） | $2 \Psi$ |
| Adam $m$（FP32） | $4 \Psi$ |
| Adam $v$（FP32） | $4 \Psi$ |
| 参数 FP32 副本 | $4 \Psi$ |
| **合计** | **$16 \Psi$ bytes** |

**符号**：$\Psi$（大写 psi）是模型参数量。

### 2.2 三个阶段

| 阶段 | 切分什么 | 显存 / GPU | 通信开销 |
|---|---|---|---|
| 基线 DP | 不切 | $16 \Psi$ | $2\Psi$（AllReduce） |
| **ZeRO-1** | 优化器状态（Adam $m, v$, FP32 副本） | $4\Psi + 12\Psi/N$ | $2\Psi$ |
| **ZeRO-2** | + 梯度 | $4\Psi + 14\Psi/N$ | $2\Psi$ |
| **ZeRO-3** | + 参数 | $16\Psi / N$ | $3\Psi$（额外 AllGather） |

**符号**：$N$ 是 GPU 数。

```text
ZeRO-3 显存最省，但通信最多。
```

### 2.3 FSDP

**FSDP**（Fully Sharded Data Parallel）：PyTorch 原生 ZeRO-3 实现。

- `FULL_SHARD` ≈ ZeRO-3
- `SHARD_GRAD_OP` ≈ ZeRO-2
- `HYBRID_SHARD` ≈ 节点内 ZeRO-3 + 节点间 DP

---

## 3. Tensor Parallel（TP）：层内切

**TP**（Megatron-LM 提出）：把单层的权重矩阵切分到多卡，**层内并行**。

### 3.1 Self-Attention 中的 TP

- **列并行 $W^Q, W^K, W^V$**：每张卡持有一部分头
  - 输出按列拼接（concat）
- **行并行 $W^O$**：每张卡处理对应头的输出
  - 输出 **AllReduce** 合并

### 3.2 FFN 中的 TP

- **列并行 $W_1$**（$d \to 4d$）：输出按列分布
- **行并行 $W_2$**（$4d \to d$）：输入对应列，输出 AllReduce 合并

**关键技巧**：列并行 + 行并行交替，AllReduce 只在 block 边界。

**通信**：每层 2 次 AllReduce（attention + FFN），**通信量大**。

**适用**：节点内（NVLink 高带宽）。TP 大小通常 = 单节点 GPU 数（如 8）。

---

## 4. Pipeline Parallel（PP）：层间切

**PP**：把模型按层切分到多卡，**层间并行**。

### 4.1 朴素 PP 的问题

- 卡 1 算前 $N/M$ 层，卡 2 算后 $N/M$ 层
- 卡 1 做完传给卡 2 → 卡 1 闲置
- 大量**气泡**（bubble，卡空闲）

### 4.2 GPipe / 1F1B / Interleaved 1F1B

| 方案 | 思路 |
|---|---|
| **GPipe** | 把 batch 切成 microbatch，沿管道流 |
| **PipeDream / 1F1B** | 前向反向交错，减少气泡 |
| **Interleaved 1F1B** | 每张卡持有不同的层 chunk（如卡 0 持有 1-4 + 13-16 层），气泡更少 |

**气泡比例**（朴素）：

$$\text{bubble ratio} = \frac{P - 1}{M}$$

**符号说明**：
- $P$：pipeline stage 数（卡数）
- $M$：microbatch 数

**适用**：跨节点（PP 通信少，只在 stage 边界传 activation）。

---

## 5. Sequence Parallel（SP）：序列维切

**问题**：长序列训练时 attention 计算 + 激活值显存巨大。

| 方案 | 思路 |
|---|---|
| **Megatron-SP** | 在 TP 基础上，把 LayerNorm/Dropout 的激活也按序列维度切 |
| **DeepSpeed-Ulysses** | 用 All-to-All 在 attention 时按头维度切；其他时按序列维度切 |
| **Ring Attention** | 多设备间环形传递 K/V 块（详见高效注意力篇） |

---

## 6. Expert Parallel（EP）：MoE 必备

**MoE 模型的特殊性**：
- 每层 N 个专家（如 8 或 256 个）
- 每个 token 只激活 $K$ 个（如 2 个）
- 总参数大，激活参数小

**EP**：把不同专家放到不同卡上。

**通信**：
- **All-to-All**：token 按路由结果发到对应卡的专家
- 计算后再 All-to-All 返回
- 每层 2 次 All-to-All，开销大

**与其他并行组合**：DP + EP + TP 是 MoE 训练标准。

---

## 7. 3D / 4D 并行组合

**3D 并行**（Megatron + DeepSpeed）：
- **DP**（外层）：扩展 batch
- **PP**（中层）：跨节点
- **TP**（内层）：节点内

**总卡数 = TP × PP × DP**。

**典型配置**（如 GPT-3 175B 训练）：
- TP = 8（单节点）
- PP = 16（跨节点）
- DP = 数据并行

**4D 并行**：加入 SP（长上下文）或 EP（MoE）。

**组合规则**：
- TP 通信最重 → 用最高带宽（节点内 NVLink）
- PP 通信轻 → 跨节点
- DP 灵活，对带宽要求最低

---

## 8. 选择并行配置

**核心约束**：
1. 单卡显存（模型 + 优化器 + 激活 + KV Cache）
2. 集群拓扑（节点内 vs 跨节点带宽）
3. 效率（减少通信和气泡）

**经验规则**：
- 模型权重单卡放不下 → 必须 TP 或 PP
- 节点内放得下一层 → TP 用满单节点，PP 跨节点
- 节点内放不下一层 → PP + TP 同时切
- Batch 大 → 加 DP / ZeRO
- 长序列 → 加 SP
- MoE → 加 EP

**例**：LLaMA-3 70B 训练，H100 80GB × 256 卡：
- TP=8, PP=4, DP=8 是常见配置

## 9. 各并行的通信开销对比

| 并行 | 通信类型 | 频率 | 量级 |
|---|---|---|---|
| DP | AllReduce gradient | 每 step | $O(\Psi)$ |
| ZeRO-3 | AllGather param + ReduceScatter grad | 每层每 step | $O(\Psi)$ 分散 |
| TP | AllReduce activation | 每层 2 次 | $O(BLD)$ |
| PP | P2P activation | 每 stage 边界 | $O(BLD)$ 小 |
| SP | All-to-All | 每层 | $O(BLD)$ |
| EP | All-to-All | 每层 2 次（MoE） | $O(BLD)$ 大 |

**符号**：$\Psi$ 参数量，$B$ batch，$L$ 序列长，$D$ hidden dim。

```text
关键：TP 通信最重（每层都通信），PP 通信最轻（只在边界）。
```

---

## 10. 最简记忆

```text
DP    数据并行：每卡完整模型，AllReduce 梯度
ZeRO  把模型状态切到多卡（1/2/3 阶段切不同部分）
TP    张量并行（层内切矩阵），通信重 → 用节点内
PP    流水线并行（层间切），通信轻 → 跨节点
SP    序列并行（长上下文），与 TP 配合
EP    专家并行（MoE 必备），All-to-All

3D 并行 = TP + PP + DP，工业标准
```

## 🎯 高频追问

1. **TP 大小为什么不能跨节点**？跨节点带宽（IB ~50GB/s）远低于节点内 NVLink（~600GB/s），TP 通信成瓶颈。

2. **PP 气泡怎么减少**？1F1B、Interleaved 1F1B、加大 microbatch 数。

3. **ZeRO-3 vs PP 怎么选**？ZeRO-3 通信多但灵活；PP 通信少但实现复杂。中小集群 ZeRO-3 + DP，大集群 3D 并行。

4. **FSDP 能替代 Megatron 吗**？中等规模可以；超大规模（千卡以上）Megatron 仍更优。

5. **MoE 的 EP 通信怎么优化**？DeepEP、Flux 等定制 All-to-All kernel。
