# Agent 产品设计与用户体验 · 面试题

## Q1: 请用一分钟说明Agent 产品设计与用户体验的核心目标与工作机制。
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

Agent 产品的核心体验是让用户理解系统能做什么、正在做什么、为何需要权限以及如何纠正和接管。应通过范围明确的入口、渐进授权、计划与进度、可编辑产物、证据和撤销机制建立信任；自主程度按风险分级，而不是用拟人化对话掩盖不确定性。

---

## Q2: 能力与预期的核心机制是什么？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

入口展示适用任务、所需数据、预计时间和限制，复杂请求先复述目标与成功标准。系统对不确定和失败要直说，避免把建议包装成已执行结果。

---

## Q3: 可控执行为什么重要，实际如何落地？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥

执行前展示高影响计划，过程中显示当前步骤、等待原因和成本，允许暂停、取消、修改与人工接管。写操作提供预览、diff、确认和可撤销窗口。

---

## Q4: Agent 产品设计与用户体验在工程落地时如何做取舍？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥🔥

过多确认会打断体验，可按风险、用户经验和组织策略动态调整；展示完整推理既不必要也可能混淆，重点展示计划、证据和动作依据；拟人化可提升亲和力，但不应误导用户认为系统具有人类判断与责任。

---

## Q5: Agent 产品设计与用户体验最常见的故障与排查重点是什么？
> 难度 ⭐⭐⭐⭐ ｜ 高频 🔥🔥

进度动画持续运行但没有真实状态，用户无法判断是否卡死；Agent 自动发送或发布内容，没有预览与撤销；失败只显示“出错了”，不提供已完成步骤、影响和恢复选择。排查时应关联运行状态、模型请求、工具调用、外部证据和最终结果，先判断是数据、模型、编排、权限还是依赖故障。
