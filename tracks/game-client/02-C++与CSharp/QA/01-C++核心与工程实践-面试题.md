# C++ 核心与工程实践 · 面试题

## Q1: 引擎对象为什么不能随便用 `shared_ptr`？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥🔥

引擎对象可能由反射、GC、世界或 Actor owner 管理，`shared_ptr` 的引用计数并不等于引擎可见性和线程安全。应使用引擎提供的强/弱引用类型，或明确 owner 与观察者的生命周期。

## Q2: 什么情况下需要虚析构函数？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

如果通过基类指针删除派生对象，基类析构函数必须是 virtual，否则只执行基类析构，造成资源泄漏或未定义行为。若类型不用于多态删除，也可以禁止继承或采用非虚析构的明确设计。

## Q3: 无锁队列最容易出什么错？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥

内存序错误、ABA、容量满处理和节点提前回收都可能导致偶发崩溃。要说明生产者/消费者数量、所有权回收方式、内存序和压力测试，而不是只说“CAS 就是线程安全”。
