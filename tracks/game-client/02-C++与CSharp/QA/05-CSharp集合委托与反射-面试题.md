# C# 集合、委托、事件与反射 · 面试题

## Q1: foreach 什么时候会装箱？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

泛型集合通常使用结构体枚举器可零分配；转成接口/非泛型 IEnumerable 后可能装箱。必须结合实际集合类型和 Profiler 判断。

## Q2: 为什么反射代码在 IL2CPP 可能失效？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥

AOT 裁剪器看不到只由反射访问的类型和成员，运行时也没有任意 JIT。需要显式注册、链接配置或源生成，并在发行平台回归。
