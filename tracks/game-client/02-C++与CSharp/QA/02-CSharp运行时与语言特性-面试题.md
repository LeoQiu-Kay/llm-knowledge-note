# C# 运行时、GC 与语言特性 · 面试题

## Q1: 装箱为什么会造成卡顿？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

值类型转成 `object` 或接口会创建托管对象并复制值，短时间大量装箱会增加分配率和 GC 压力。用泛型 API、缓存对象或非分配路径替代，并用 Profiler 确认热点。

## Q2: `async/await` 是否一定开新线程？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

不一定。它是异步控制流，具体线程取决于 await 的任务和调度器；Unity 中常会捕获主线程上下文。回答要说明 IO、Task、Job 的线程归属，以及取消和异常如何回到主线程处理。

## Q3: 事件为什么会造成对象无法回收？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

发布者持有订阅者委托，若发布者寿命更长而订阅者未解绑，GC 仍把订阅者视为可达。组件禁用、销毁和场景切换时应解除订阅，或使用生命周期托管的信号系统。
