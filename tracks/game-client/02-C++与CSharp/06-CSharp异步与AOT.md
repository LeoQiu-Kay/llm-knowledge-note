# C# 异步、线程与 AOT

> **优先级**：Unity P0/P1。

## 1. 三类异步

Coroutine 是主线程时序；Task/async 适合 IO 和组合；Job/Burst 适合受约束的数据并行。异步 API 要明确 continuation 线程、取消、超时、异常和对象销毁后的行为。

## 2. 主线程回调

Unity API 通常只能在主线程调用。网络线程完成后应投递主线程队列，回调前检查场景 generation 和请求 ID。不要在主线程 `Wait()` 或 `.Result`，否则可能死锁并制造卡顿。

## 3. IL2CPP 与裁剪

AOT 不支持任意运行时 JIT；泛型、反射、动态代理和表达式树要在目标平台验证。保留类型、避免隐式反射依赖、用源生成和链接配置保证发行包行为与编辑器一致。

### 高频追问

#### Q1. async 任务如何取消？
通过 CancellationToken 贯穿 IO、资源加载和业务流程，在场景卸载/重复请求时取消；取消后不要继续更新 UI 或持有已销毁对象。

#### Q2. 为什么编辑器正常、IL2CPP 崩溃？
可能依赖 JIT、反射类型被裁剪、泛型实例未生成或平台 API 不支持。必须在目标平台构建、开启剥离级别并覆盖反射/序列化路径。
