# Unity 对象模型、生命周期与运行时 · 面试题

## Q1: Awake 与 Start 的顺序能否跨对象依赖？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

不能依赖不同对象之间的相对顺序。可以用显式 Bootstrap、Script Execution Order 或两阶段初始化；动态 Instantiate 的对象还会在生成时走自己的生命周期。

## Q2: 为什么 `FixedUpdate` 可能一帧执行多次？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

物理使用固定步长，渲染帧慢时引擎会补多个物理步，渲染帧快时可能没有物理步。物理读写放 FixedUpdate，视觉跟随放 Update/LateUpdate，并避免把两种 deltaTime 混用。

## Q3: 场景卸载后异步回调如何防止空引用？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥

为请求绑定取消令牌或 generation，回调执行前检查对象是否仍属于当前场景、是否 active、句柄是否是最新请求；卸载阶段先取消任务、解除事件，再释放资源。
