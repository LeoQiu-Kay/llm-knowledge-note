# Unity 渲染、性能工具与工程化 · 面试题

## Q1: Draw Call 降了但帧率没升，为什么？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

瓶颈可能在 GPU 片元、纹理带宽、Shader、IO 或脚本；Draw Call 只是 CPU 提交指标。要同时看 CPU/GPU frame time、overdraw、材质状态和目标设备。

## Q2: 为什么要在目标机上做性能测试？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

编辑器和开发机有额外开销，移动端还存在带宽、温度和降频。只有目标机的固定场景、分辨率和采样才能说明真实帧时间和功耗。

## Q3: CI 中最值得自动化的 Unity 检查有哪些？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

编译、资源引用/命名校验、Addressables 构建、包体与依赖报告、冒烟测试、符号和版本信息生成。失败时保留日志与构建元数据，支持回滚而不是只发一个二进制包。
