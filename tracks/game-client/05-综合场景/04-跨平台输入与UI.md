# 跨平台输入、UI 与本地化

## 设计原则

设备层把键鼠、手柄、触屏和陀螺仪映射到统一动作；Gameplay 只消费动作和设备能力，不读取具体按键。UI 根据平台切换导航、焦点、提示图标、Safe Area 和输入法。

## 工程细节

本地化文本长度、字体回退、RTL、数字/时间格式、语音和无障碍颜色都要进入验收。不同平台的窗口、暂停、后台、存储权限和手柄断开事件由平台适配层统一处理。

## 测试矩阵

建立设备/分辨率/输入组合矩阵，自动截图比对关键页面；人工验证焦点循环、返回键、触控热区、字体溢出和横竖屏切换。

### 高频追问

#### Q1. 为什么输入要和 UI 解耦？
同一动作可能来自不同设备，UI 模态还会改变输入焦点。统一动作层可复用 Gameplay 和自动化测试，避免按键判断散落各处。

#### Q2. 本地化为什么会影响布局性能？
文本长度改变会触发布局重建、字体生成和批处理变化；应预留布局、缓存字体并对长文本做异步/分帧更新。
