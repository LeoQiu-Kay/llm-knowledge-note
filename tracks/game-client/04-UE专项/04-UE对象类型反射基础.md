# UE 对象类型、反射与基础类型

> **优先级**：P0。

## 1. UObject 家族

UObject 提供反射、序列化和 GC；AActor 才能进入世界、拥有 Transform 并参与网络；UActorComponent 复用能力；USTRUCT 表达值数据；UDataAsset/Primary Data Asset 承载配置。选择类型要看生命周期、编辑器暴露、复制和资源引用。

## 2. 宏与属性

`UCLASS`、`UPROPERTY`、`UFUNCTION`、`USTRUCT` 把类型和成员交给 UHT 生成反射代码。属性 specifier 同时影响编辑器、蓝图、复制和存档，不能只靠命名猜行为。容器优先使用引擎反射支持的 `TArray/TMap/TSet`。

## 3. 引用

强引用让 GC 跟踪对象，弱引用适合可选资源和观察者；软对象路径支持延迟加载。不要保存跨关卡的裸 UObject 指针，关卡卸载、PIE 多世界和热重载都会改变有效性。

### 高频追问

#### Q1. AActor 与 UObject 的关键区别？
AActor 属于世界，具有 Transform、组件、BeginPlay/EndPlay 和网络复制；UObject 是更轻的反射对象，不自动存在于关卡世界。

#### Q2. USTRUCT 什么时候比 UObject 合适？
数据是值语义、生命周期随 owner、无需独立 GC/编辑器对象和网络身份时，USTRUCT 更轻；需要共享身份或独立资源时用 UObject/Asset。
