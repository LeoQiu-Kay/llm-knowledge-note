# 图形学、客户端架构与性能 · 面试题

## Q1: 怎么区分 CPU bound 和 GPU bound？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

看 CPU 主线程/渲染线程和 GPU frame time 的时间线：CPU 满而 GPU 有余量通常是提交、脚本、UI 或 GC；GPU 满则检查片元、阴影、后处理、带宽。用目标机和固定场景验证，不能只看 Draw Call。

## Q2: 客户端分层如何避免“上帝类”？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

按输入、用例、领域状态、表现和基础设施拆分，依赖通过接口或注入连接；每个模块有明确启动/停止和资源 owner。事件总线只传领域事件，不把所有状态都藏在全局单例里。

## Q3: 性能优化报告应该包含哪些数据？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

至少包含目标设备、版本、场景、分辨率、平均与 P95/1% low 帧时间、峰值内存、GC、GPU pass、首屏和网络指标。说明优化前基线、改动、收益和回归开关，保证结果可复现。
