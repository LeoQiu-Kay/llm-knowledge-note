# 游戏数学与碰撞进阶

> **优先级**：P0。数学题要落到坐标、误差、插值和实际碰撞管线。

## 1. 旋转与插值

欧拉角便于展示但存在万向节锁；四元数适合组合和球面插值，插值前要处理点积为负的符号翻转。位置平滑可用线性插值，速度/相机跟随要根据帧率选择指数平滑或固定步长积分。

## 2. 碰撞检测管线

Broad phase 用网格、BVH、AABB 筛掉绝大多数不相交物体；narrow phase 再做球体、胶囊体、OBB、SAT 或 GJK。连续碰撞检测针对高速物体计算扫掠体，代价更高，需按对象重要性启用。

## 3. 数值稳定性

比较浮点数用 epsilon，归一化前检查长度接近零；射线/平面求交需处理平行和背面。物理与网络同步要固定 tick、限制最大 deltaTime，并对远距离坐标考虑浮点精度和世界原点重定位。

### 高频追问

#### Q1. Lerp 为什么不一定是匀速？
固定 t 的线性插值只保证参数线性，若每帧用 `t += speed * deltaTime` 且不同距离共用 speed，会导致到达时间不同；应按距离归一化或使用 MoveTowards。

#### Q2. SAT 的核心是什么？
若两个凸物体分离，必存在一个轴使它们在该轴上的投影区间不重叠。对所有候选轴做投影比较即可判断相交，轴集合来自面法线和边叉积。
