# 渲染管线、材质与光照模型

> **优先级**：基础 P0，深入 P1/P2。

## 1. 从顶点到屏幕

顶点经模型、视图、投影变换进入裁剪空间，透视除法后光栅化；深度/模板测试决定片元是否保留，Shader 计算材质与光照，最后经过后处理和色调映射输出。面试要能指出 CPU 提交、GPU 顶点、片元和带宽分别可能成为瓶颈。

## 2. PBR 与阴影

PBR 通常用 base color、metallic、roughness、normal 等参数描述材质，能量守恒比经验叠加更稳定。阴影可用 shadow map、级联、PCF、VSM 等，分辨率、级联数量和采样次数直接影响 GPU 与内存。

## 3. 透明、后处理与移动端

透明物体难以写入深度，通常需要排序并带来 overdraw；粒子和 UI 是移动端常见热点。后处理要按目标设备裁剪 pass，HDR、Bloom、TAA、SSR 等效果都要有质量档位和动态降级。

### 高频追问

#### Q1. 为什么透明物体很难完全合批？
透明需要按深度排序，且混合依赖前面已经写入的颜色；不同材质、排序层和深度状态会打断批处理。应减少透明覆盖面积并使用裁剪、粒子合批和 LOD。

#### Q2. 纹理压缩如何选择？
根据平台 GPU 支持、颜色/法线/高光语义和可接受失真选择格式；同时看显存、带宽、解压时间和 mip 链，而不是只看文件大小。
