# 概率与信息论

> 大模型训练与推理中的概率论基础，KL/CE/PPL 是面试必问。

---

## Q1: 熵（Entropy）的定义和直观意义？

**答**：
$$H(P) = -\sum_x P(x) \log P(x)$$

- **直观**：衡量一个分布的不确定性 / 信息量。分布越均匀 → 熵越大；越确定 → 熵越小（确定分布熵为 0）。
- 单位：以 $\log_2$ 为底是 bit，以 $\ln$ 为底是 nat。
- **在 LM 中**：词表上的分布越尖锐，预测越自信，熵越低。

---

## Q2: 交叉熵（Cross Entropy）与熵的关系？

**答**：
$$H(P, Q) = -\sum_x P(x) \log Q(x)$$

- $P$ 是真实分布，$Q$ 是预测分布。
- **关系**：$H(P, Q) = H(P) + D_{KL}(P \| Q)$
- 真实分布 $H(P)$ 是常数（与模型无关），所以**最小化交叉熵等价于最小化 KL 散度**。
- LM 训练时，$P$ 是 one-hot（真实下一个 token），所以交叉熵退化为 $-\log Q(x_{\text{true}})$，也就是 NLL（Negative Log Likelihood）。

---

## Q3: KL 散度（KL Divergence）？

**答**：
$$D_{KL}(P \| Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$$

**关键性质**：
1. **非负**：$D_{KL} \geq 0$，当且仅当 $P = Q$ 时为 0（Gibbs 不等式）
2. **非对称**：$D_{KL}(P \| Q) \neq D_{KL}(Q \| P)$，所以不是距离
3. **方向性**：
   - $D_{KL}(P \| Q)$ "前向 KL"：当 $P(x) > 0$ 时强制 $Q(x) > 0$，倾向于 **覆盖（mode-covering）**
   - $D_{KL}(Q \| P)$ "反向 KL"：倾向于 **寻众（mode-seeking）**，会聚焦到 $P$ 的高密度区

**LLM 中的应用**：
- RLHF/DPO 中用 KL 惩罚约束 RL 模型不偏离 SFT 参考模型
- 知识蒸馏中老师模型与学生模型分布的 KL

---

## Q4: 为什么 LM 用 PPL（困惑度）作为评价指标？

**答**：
$$\text{PPL} = \exp\left(-\frac{1}{N}\sum_{i=1}^N \log P(x_i | x_{<i})\right) = \exp(H)$$

- **本质**：PPL 是交叉熵的指数形式。
- **直观**：可理解为模型在每个位置"等效"地从多少个候选 token 中随机选一个。PPL=1 表示完美预测，PPL=词表大小 表示完全随机。
- **为什么用 PPL 而不是 CE**：尺度更直观，与词表大小可比，跨数据集易解释。
- **局限**：仅衡量似然，不能反映生成质量、事实性、对齐效果。

---

## Q5: JS 散度（Jensen-Shannon Divergence）与 KL 的区别？

**答**：
$$D_{JS}(P \| Q) = \frac{1}{2} D_{KL}(P \| M) + \frac{1}{2} D_{KL}(Q \| M), \quad M = \frac{P+Q}{2}$$

- **对称**：$D_{JS}(P \| Q) = D_{JS}(Q \| P)$
- **有界**：$0 \leq D_{JS} \leq \log 2$
- 平方根是合法的距离度量
- GAN 训练用 JS（原始公式），但训练不稳定，催生了 Wasserstein 距离

---

## Q6: 互信息（Mutual Information）？

**答**：
$$I(X; Y) = D_{KL}(P(X,Y) \| P(X)P(Y)) = H(X) - H(X|Y)$$

- 衡量两个随机变量的依赖程度，独立时为 0。
- LLM 应用：信息瓶颈理论分析表示学习；对比学习目标（InfoNCE）可视为 MI 下界。

---

## Q7: 最大似然估计（MLE）与最大后验估计（MAP）？

**答**：
- **MLE**：$\hat\theta_{MLE} = \arg\max_\theta P(D | \theta)$
- **MAP**：$\hat\theta_{MAP} = \arg\max_\theta P(\theta | D) = \arg\max_\theta P(D|\theta) P(\theta)$

**关系**：
- MAP = MLE + 先验
- MAP 中先验是高斯 → 等价于 L2 正则化
- MAP 中先验是拉普拉斯 → 等价于 L1 正则化
- LM 的训练目标就是 MLE：最大化数据序列的对数似然。

---

## Q8: 交叉熵损失的梯度为什么这么简单？

**答**：对 softmax + 交叉熵的组合：
$$\frac{\partial L}{\partial z_i} = q_i - p_i$$

其中 $z$ 是 logits，$q$ 是 softmax 输出，$p$ 是真实标签。
- **简洁原因**：softmax 的导数和 log 的导数恰好相消。
- **数值稳定**：直接用 logits 计算（log-sum-exp trick），不要分开算 softmax 再 log。
- PyTorch 的 `CrossEntropyLoss` 内部接收 logits 也是因此。

## 🎯 高频追问

1. **为什么 LLM loss 用 CE 而不是 MSE**？分类任务，MSE 梯度在饱和区消失，CE 与 softmax 配合梯度平稳。
2. **Label Smoothing 怎么改变交叉熵**？将 one-hot 改为 $(1-\epsilon) \cdot \text{onehot} + \epsilon / K$，相当于在 CE 中增加了一个与均匀分布的 KL 项，缓解过度自信。
3. **温度 $T$ 如何影响 softmax**？$T \to 0$ 接近 argmax（尖锐），$T \to \infty$ 接近均匀（平滑）。蒸馏中用大 $T$ 暴露更多"暗知识"。
