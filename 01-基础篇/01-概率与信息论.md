# 概率与信息论

> 不要先背"熵是不确定性"这句话，而是直接看公式为什么会推出这个含义。
> 下面从 **熵 → 交叉熵 → KL 散度 → PPL** 四个公式一步一步拆。每个符号都先解释。

---

## 1. 熵 Entropy：为什么这个公式表示"不确定性"？

公式：

$$H(P) = -\sum_x P(x) \log P(x)$$

**符号说明**：
- $P$：一个**离散概率分布**（例如词表上的概率分布，所有 $P(x)$ 之和为 1）
- $x$：一个可能的事件 / 取值（如某个 token）
- $P(x)$：事件 $x$ 发生的概率（$0 \leq P(x) \leq 1$）
- $\log$：对数（用自然对数 $\ln$ 时单位是 nat，用 $\log_2$ 时单位是 bit）
- $\sum_x$：对所有可能事件求和
- $H(P)$：分布 $P$ 的熵（一个标量）

先不要看整体，先看每一项：

$$-P(x) \log P(x)$$

---

### 1.1 为什么有 $-\log P(x)$？

$-\log P(x)$ 表示：

> 事件 $x$ 发生时，它带来的"惊讶程度"或"信息量"。

概率越小，越意外，信息量越大：

| $P(x)$ | $-\log P(x)$ | 含义 |
|---|---:|---|
| 1 | 0 | 完全确定，没有惊讶 |
| 0.5 | 0.693 | 有一点不确定 |
| 0.1 | 2.303 | 比较意外 |
| 0.01 | 4.605 | 非常意外 |

---

### 1.2 为什么还要乘 $P(x)$？

熵是看**整个分布的平均不确定性**，所以要对每个事件做**按概率加权**的平均：

某事件信息量是 $-\log P(x)$，发生概率是 $P(x)$，对整体熵的贡献是 $P(x) \cdot (-\log P(x))$。

对所有事件求和：

$$H(P) = -\sum_x P(x) \log P(x) = \mathbb{E}_{x \sim P}[-\log P(x)]$$

**符号补充**：$\mathbb{E}_{x \sim P}[f(x)]$ = 按分布 $P$ 采样 $x$，对 $f(x)$ 求期望。

```text
熵 = 所有事件信息量的期望。
```

---

### 1.3 为什么分布越均匀，熵越大？

**情况 A：完全确定** $P(A)=1, P(B)=0$
$$H = -1 \cdot \log 1 - 0 \cdot \log 0 = 0$$
（约定 $0 \log 0 = 0$）

**情况 B：均匀两选一** $P(A)=P(B)=0.5$
$$H = -0.5 \log 0.5 - 0.5 \log 0.5 = 0.693$$

**情况 C：均匀四选一** $P(A)=...=P(D)=0.25$
$$H = -4 \times 0.25 \log 0.25 = 1.386$$

```text
可能结果越多、越平均，越难猜，熵越大。
```

---

## 2. 交叉熵 Cross Entropy：为什么能作为 loss？

公式：

$$H(P, Q) = -\sum_x P(x) \log Q(x)$$

**符号说明**：
- $P$：**真实分布**（数据的真实标签分布）
- $Q$：**模型预测的分布**（如 softmax 输出）
- $P(x), Q(x)$：同一事件 $x$ 在两个分布下的概率
- $H(P, Q)$：交叉熵（一个标量）

和熵对比：

| 公式 | 用哪个 log |
|---|---|
| 熵 $H(P)$ | $\log P(x)$ |
| 交叉熵 $H(P, Q)$ | $\log Q(x)$ |

只有这一处不同。

---

### 2.1 公式的含义

$$H(P, Q) = \mathbb{E}_{x \sim P}[-\log Q(x)]$$

> 真实数据按 $P$ 产生，但模型用 $Q$ 去预测。交叉熵 = 模型在真实数据上的平均惊讶程度。

- $Q(x_{\text{真实}})$ 高 → $-\log Q$ 小 → loss 小
- $Q(x_{\text{真实}})$ 低 → $-\log Q$ 大 → loss 大

---

### 2.2 one-hot 情况下退化为 $-\log Q(x_{\text{true}})$

LLM 训练中真实标签是 one-hot。假设词表 = {北京、上海、广州}，真实下一个 token 是"北京"：

$$P(\text{北京}) = 1, \quad P(\text{上海}) = P(\text{广州}) = 0$$

代入交叉熵：

$$H(P, Q) = -[1 \cdot \log Q(\text{北京}) + 0 + 0] = -\log Q(\text{北京})$$

```text
LM 的 token-level cross entropy = -log Q(真实 token)
其他项被 0 消掉了。
```

---

### 2.3 模型给真实 token 的概率越高，loss 越小

| 模型 | $Q(\text{北京})$ | loss = $-\log Q$ |
|---|---:|---:|
| A | 0.9 | 0.105 |
| B | 0.1 | 2.303 |
| C | 0.01 | 4.605 |

```text
最小化交叉熵 = 把真实 token 的预测概率推高。
```

## 3. KL 散度：为什么表示两个分布的差距？

公式：

$$D_{KL}(P \| Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$$

**符号说明**：
- $P, Q$：两个概率分布
- $\frac{P(x)}{Q(x)}$：对同一事件 $x$，$P$ 给的概率 ÷ $Q$ 给的概率
- $D_{KL}(P \| Q)$：从 $P$ 到 $Q$ 的 KL 散度（标量）
- 双竖线 $\|$ 只是记号，不代表范数

---

### 3.1 $\frac{P(x)}{Q(x)}$ 表示什么？

> 对同一事件 $x$，真实分布认为它多可能，模型认为它多可能。

- $P(x) = Q(x)$：比值为 1，$\log 1 = 0$，没有差异
- $Q(x) \ll P(x)$（如 $P = 0.5, Q = 0.01$）：比值 50，$\log 50$ 很大
  - 真实认为重要，模型几乎没给概率 → KL 惩罚大

---

### 3.2 为什么要乘 $P(x)$？

KL 是站在真实分布 $P$ 的角度看差异：

$$D_{KL}(P \| Q) = \mathbb{E}_{x \sim P}\left[\log \frac{P(x)}{Q(x)}\right]$$

- $P(x)$ 大的事件 → 权重大，差异被重点考虑
- $P(x)$ 小的事件 → 权重小，差异无关紧要

```text
按真实分布 P 采样，看 Q 平均偏离 P 多少。
```

---

### 3.3 KL 的核心性质

1. **非负**：$D_{KL}(P \| Q) \geq 0$，仅当 $P = Q$ 时为 0（Gibbs 不等式）
2. **非对称**：$D_{KL}(P \| Q) \neq D_{KL}(Q \| P)$ → **不是距离**
3. **可能无界**：$Q(x) \to 0$ 而 $P(x) > 0$ 时，$D_{KL} \to \infty$

---

## 4. 三者关系：从公式直接推

**最重要的公式**：

$$H(P, Q) = H(P) + D_{KL}(P \| Q)$$

### 4.1 推导

从 KL 出发：

$$D_{KL}(P \| Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$$

利用 $\log \frac{a}{b} = \log a - \log b$：

$$= \sum_x P(x) [\log P(x) - \log Q(x)]$$

拆开：

$$= \underbrace{\sum_x P(x) \log P(x)}_{= -H(P)} - \underbrace{\sum_x P(x) \log Q(x)}_{= -H(P,Q)}$$

得：

$$D_{KL}(P \| Q) = -H(P) + H(P, Q)$$

移项：

$$\boxed{H(P, Q) = H(P) + D_{KL}(P \| Q)}$$

---

### 4.2 这个关系的含义

```text
交叉熵 = 真实分布本身的不确定性 + 模型分布和真实分布的差距
H(P,Q) =        H(P)             +     D_KL(P||Q)
```

- $H(P)$：真实分布自己有多难预测（模型无法改变，是常数）
- $D_{KL}(P \| Q)$：模型 $Q$ 额外带来的错误（模型唯一能改的）

---

### 4.3 为什么"最小化交叉熵等价于最小化 KL"？

训练数据固定时，$P$ 固定，$H(P)$ 是常数。

$$\min_Q H(P, Q) = \min_Q [H(P) + D_{KL}(P \| Q)] = \min_Q D_{KL}(P \| Q)$$

```text
最小化交叉熵 = 让模型分布 Q 尽量接近真实分布 P。
```

这就是 LM 训练的数学基础。

---

## 5. KL 为什么有方向性？

两个方向：

$$D_{KL}(P \| Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$$

$$D_{KL}(Q \| P) = \sum_x Q(x) \log \frac{Q(x)}{P(x)}$$

**关键差别**：前向用 $P(x)$ 加权，反向用 $Q(x)$ 加权。

---

### 5.1 前向 KL：$D_{KL}(P \| Q)$ — Mode-covering

按 $P(x)$ 加权，重点关心：

```text
P 认为重要的地方，Q 有没有覆盖。
```

如果 $P(x) > 0$ 但 $Q(x) \approx 0$：

$$\frac{P(x)}{Q(x)} \to \infty \quad \Rightarrow \quad D_{KL} \to \infty$$

→ 前向 KL 倾向于覆盖 $P$ 的所有可能性（"宁可涂宽也不漏"）。

---

### 5.2 反向 KL：$D_{KL}(Q \| P)$ — Mode-seeking

按 $Q(x)$ 加权，重点关心：

```text
Q 自己放了概率的地方，在 P 里面是不是也合理。
```

如果 $Q(x) > 0$ 但 $P(x) \approx 0$：

$$D_{KL} \to \infty$$

→ 反向 KL 不敢把概率放到 $P$ 认为不可能的地方（"龟缩到高概率区"）。

---

### 5.3 数学例子

真实分布 $P(A) = P(B) = 0.5$。

模型选择 1：完美覆盖 $Q(A) = Q(B) = 0.5$
$$D_{KL}(P \| Q) = 0$$

模型选择 2：只覆盖一个 $Q(A) = 1, Q(B) = 0$

- 前向 KL：$D_{KL}(P \| Q) = 0.5 \log \frac{0.5}{1} + 0.5 \log \frac{0.5}{0} \to \infty$
- 反向 KL：$D_{KL}(Q \| P) = 1 \cdot \log \frac{1}{0.5} + 0 = \log 2$（有限）

```text
前向 KL 极度讨厌"漏掉模式"。
反向 KL 对"只选一个模式"惩罚有限 → mode-seeking。
```

---

### 5.4 LLM 中怎么选？

- **预训练 / SFT（CLM 训练）**：等价于最小化 $D_{KL}(P_{\text{data}} \| P_{\text{model}})$（前向 KL，覆盖数据所有模式）
- **RLHF 的 KL 约束**：$D_{KL}(\pi_\theta \| \pi_{\text{ref}})$（反向 KL，让 policy 不偏离 SFT）

**符号补充**：
- $\pi_\theta$：被训练的策略（policy 模型）
- $\pi_{\text{ref}}$：参考模型（冻结的 SFT 模型）

## 6. PPL（困惑度）：为什么是交叉熵的指数？

> 沿用前文约定：$P$ 是真实分布，$Q$ 是模型分布。
> 测试集上"真实下一个 token"是数据给的，**所以 $x_i$ 来自 $P$；模型给 $x_i$ 打的概率是 $Q(x_i \mid x_{<i})$**。

LM 在测试集上的平均负对数似然（即平均交叉熵）：

$$H = -\frac{1}{N} \sum_{i=1}^N \log Q(x_i \mid x_{<i})$$

**符号说明**：
- $N$：序列长度
- $x_i$：第 $i$ 个真实 token（来自真实分布 $P$）
- $x_{<i}$：第 $i$ 个之前的所有真实 token
- $Q(x_i \mid x_{<i})$：**模型**预测 $x_i$ 的条件概率
- $H$：平均交叉熵

**PPL 定义**：

$$\text{PPL} = \exp(H) = \exp\left(-\frac{1}{N} \sum_{i=1}^N \log Q(x_i \mid x_{<i})\right)$$

---

### 6.1 为什么取指数？

利用 $\exp\left(\frac{1}{N} \sum \log a_i\right) = (\prod a_i)^{1/N}$：

$$\text{PPL} = \left(\prod_{i=1}^N \frac{1}{q_i}\right)^{1/N}, \quad q_i = Q(x_i \mid x_{<i})$$

**符号**：$q_i$ = 模型给第 $i$ 个真实 token 的概率（来自模型分布 $Q$）。

**含义**：PPL 是**模型给真实 token 的概率倒数的几何平均**。

---

### 6.2 PPL = "平均在几个候选词里选"

假设模型每步都给真实 token 同样概率 $q$：

$$\text{PPL} = \left(\frac{1}{q^N}\right)^{1/N} = \frac{1}{q}$$

| 模型平均概率 $q$ | PPL | 直观解释 |
|---:|---:|---|
| 1.0 | 1 | 完美预测 |
| 0.5 | 2 | 平均在 2 个等可能里猜 |
| 0.1 | 10 | 平均在 10 个候选里猜 |
| 0.01 | 100 | 平均在 100 个候选里猜 |

```text
PPL ≈ 1 / 模型给真实 token 的平均概率
```

---

### 6.3 比较 PPL 时的注意事项

1. **必须同 tokenizer / 同测试集**：词表不同则 PPL 不可比
2. **PPL 低 ≠ 生成质量好**：PPL 只衡量似然，不衡量事实性、有用性
3. **跨语言不可直接比**：不同语言 token 信息密度不同

## 7. 其他相关概念（简述）

### 7.1 JS 散度

$$D_{JS}(P \| Q) = \frac{1}{2} D_{KL}(P \| M) + \frac{1}{2} D_{KL}(Q \| M), \quad M = \frac{P + Q}{2}$$

**符号**：$M$ 是 $P$ 和 $Q$ 的平均分布。

性质：对称、有界（$0 \leq D_{JS} \leq \log 2$）、$\sqrt{D_{JS}}$ 是合法距离。

GAN 原始目标用 JS，但训练不稳（后被 Wasserstein 替代）。

### 7.2 互信息

$$I(X; Y) = D_{KL}(P(X, Y) \| P(X) P(Y)) = H(X) - H(X \mid Y)$$

**符号**：
- $P(X, Y)$：联合分布
- $P(X) P(Y)$：独立时的乘积
- $H(X \mid Y)$：已知 $Y$ 时 $X$ 的条件熵

含义：衡量 $X, Y$ 的依赖程度，独立时为 0。

### 7.3 MLE / MAP

**MLE（最大似然）**：

$$\hat\theta_{\text{MLE}} = \arg\max_\theta P(D \mid \theta) = \arg\max_\theta \prod_i P(x_i \mid \theta)$$

**符号**：$D$ = 训练数据集，$\theta$ = 模型参数。

**MAP（最大后验）**：

$$\hat\theta_{\text{MAP}} = \arg\max_\theta P(\theta \mid D) = \arg\max_\theta P(D \mid \theta) P(\theta)$$

**符号**：$P(\theta)$ = 参数的先验分布。

- 高斯先验 ↔ L2 正则
- 拉普拉斯先验 ↔ L1 正则

## 8. 最简记忆

```text
熵：
  自己用自己预测自己
  H(P) = E_P[-log P(x)]

交叉熵：
  用 Q 去预测 P
  H(P,Q) = E_P[-log Q(x)]

KL：
  用 Q 代替 P 多出来的代价
  KL(P||Q) = E_P[log P(x) - log Q(x)] = H(P,Q) - H(P)

PPL：
  交叉熵取指数 → "平均在几个候选里猜"
  PPL = exp(H)
```

最关键的关系：

$$H(P, Q) = H(P) + D_{KL}(P \| Q)$$

```text
固定 P 时：最小化交叉熵 ⇔ 最小化 KL ⇔ 让 Q 接近 P。
```

## 🎯 高频追问

1. **为什么 LLM 用 CE 而不是 MSE**？分类任务上 MSE 梯度在饱和区消失；CE 与 softmax 配合，梯度形式为 $q - p$（softmax 输出减真实标签），简洁稳定。

2. **Softmax + CE 的梯度为什么这么简洁**？$\frac{\partial L}{\partial z_i} = q_i - p_i$（$z$ 是 logits，$q$ 是 softmax 输出，$p$ 是真实标签）。softmax 的导数与 log 的导数恰好相消。

3. **Label Smoothing 怎么改变交叉熵**？真实标签从 one-hot 改成 $(1 - \epsilon) \cdot \text{onehot} + \epsilon / K$（$\epsilon$ 是平滑系数，$K$ 是类别数）。等价于在 CE 中加入一个与均匀分布的 KL 项，缓解过度自信。

4. **温度 $T$ 如何影响 softmax**？$Q_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$（$Q$ 是 softmax 输出，即模型分布）。$T \to 0$ 接近 argmax；$T \to \infty$ 接近均匀。蒸馏中用大 $T$ 暴露更多"暗知识"。

5. **RLHF 的 KL 是前向还是反向**？$D_{KL}(\pi_\theta \| \pi_{\text{ref}})$ 是反向 KL（policy 在前），让 policy 倾向 mode-seeking——不敢偏离 SFT 模型，这正是我们想要的"约束"。
