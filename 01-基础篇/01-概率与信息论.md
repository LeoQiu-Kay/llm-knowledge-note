# 概率与信息论

> 不要先背"熵是不确定性"这句话，而是直接看公式为什么会推出这个含义。
> 下面从 **熵 → 交叉熵 → KL 散度 → PPL** 四个公式一步一步拆。

---

## 1. 熵 Entropy：为什么这个公式表示"不确定性"？

熵的公式：

$$H(P) = -\sum_x P(x) \log P(x)$$

先不要看整体，先看每一项：

$$-P(x) \log P(x)$$

---

### 1.1 为什么有 $-\log P(x)$？

$$-\log P(x)$$

可以理解为：

> 事件 $x$ 发生时，它带来的"惊讶程度"或者"信息量"。

概率越小，越意外，信息量越大。用自然对数为例：

| 概率 $P(x)$ | $-\log P(x)$ | 含义 |
|---|---:|---|
| 1 | 0 | 完全确定，没有惊讶 |
| 0.5 | 0.693 | 有一点不确定 |
| 0.1 | 2.303 | 比较意外 |
| 0.01 | 4.605 | 非常意外 |

所以 $-\log P(x)$ 表示：

```text
这个事件如果发生，它有多"意外"。
```

---

### 1.2 为什么还要乘 $P(x)$？

熵不是看某一个事件的信息量，而是看**整个分布的平均不确定性**。

某事件发生概率是 $P(x)$，信息量是 $-\log P(x)$，对整体熵的贡献是：

$$P(x) \cdot (-\log P(x)) = -P(x) \log P(x)$$

对所有可能事件求和：

$$H(P) = -\sum_x P(x) \log P(x) = \mathbb{E}_{x \sim P}[-\log P(x)]$$

所以熵 = **所有事件信息量的期望**。

---

### 1.3 为什么分布越均匀，熵越大？

**情况 A：完全确定** $P(A)=1, P(B)=0$

$$H(P) = -1 \cdot \log 1 - 0 \cdot \log 0 = 0$$

（约定 $0 \log 0 = 0$）

**情况 B：均匀分布** $P(A)=P(B)=0.5$

$$H(P) = -0.5 \log 0.5 - 0.5 \log 0.5 = 0.693$$

**情况 C：四个均匀** $P(A)=P(B)=P(C)=P(D)=0.25$

$$H(P) = -4 \times 0.25 \log 0.25 = -\log 0.25 = 1.386$$

```text
可能结果越多、越平均，越难猜，熵越大。
```

---

### 1.4 熵的数学核心

$$H(P) = \mathbb{E}_{x \sim P}[-\log P(x)]$$

> 按真实分布 $P$ 采样一个事件后，这个事件平均会带来多少信息量。

这就是为什么熵表示"不确定性"。

---

## 2. 交叉熵 Cross Entropy：为什么能作为 loss？

公式：

$$H(P, Q) = -\sum_x P(x) \log Q(x)$$

和熵对比：

| | 公式中的 log |
|---|---|
| 熵 $H(P)$ | $\log P(x)$ |
| 交叉熵 $H(P,Q)$ | $\log Q(x)$ |

只有这一处不同。

---

### 2.1 公式的含义

$$H(P, Q) = \mathbb{E}_{x \sim P}[-\log Q(x)]$$

> 真实数据按 $P$ 产生，但模型用 $Q$ 去预测。交叉熵 = 模型在真实数据上的平均惊讶程度。

- 模型给真实事件的概率 $Q(x)$ 高 → $-\log Q(x)$ 小 → loss 小
- 模型给真实事件的概率 $Q(x)$ 低 → $-\log Q(x)$ 大 → loss 大

所以交叉熵天然适合作为 loss。

---

### 2.2 one-hot 情况下为什么退化为 $-\log Q(x_{\text{true}})$？

LLM 训练中真实标签是 one-hot。假设词表有"北京、上海、广州"，真实下一个 token 是"北京"，那么：

$$P(\text{北京}) = 1, \quad P(\text{上海}) = 0, \quad P(\text{广州}) = 0$$

代入交叉熵公式：

$$H(P, Q) = -[1 \cdot \log Q(\text{北京}) + 0 \cdot \log Q(\text{上海}) + 0 \cdot \log Q(\text{广州})]$$

$$= -\log Q(\text{北京}) = -\log Q(x_{\text{true}})$$

这就是 **LM token-level cross entropy 的核心**——其他项都被 0 消掉了，只剩真实 token 那一项。

---

### 2.3 模型给真实 token 的概率越高，loss 越小

| 模型 | $Q(\text{北京})$ | $-\log Q(\text{北京})$ |
|---|---:|---:|
| A | 0.9 | 0.105 |
| B | 0.1 | 2.303 |
| C | 0.01 | 4.605 |

```text
最小化交叉熵 = 把真实 token 的预测概率推高。
```

---

## 3. KL 散度：为什么表示两个分布的差距？

公式：

$$D_{KL}(P \| Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$$

逐项看：

$$P(x) \log \frac{P(x)}{Q(x)}$$

---

### 3.1 $\frac{P(x)}{Q(x)}$ 表示什么？

> 对同一事件 $x$，真实分布认为它多可能，模型认为它多可能。

- 如果 $P(x) = Q(x)$：$\frac{P}{Q} = 1$，$\log 1 = 0$，没有差异
- 如果 $Q(x) \ll P(x)$（如 $P=0.5, Q=0.01$）：$\frac{P}{Q} = 50$，$\log 50$ 很大
  - 真实认为重要，模型几乎没给概率 → KL 惩罚大
- 如果 $Q(x) \gg P(x)$：$\log$ 为负，但被加权抑制（见下）

---

### 3.2 为什么要乘 $P(x)$？

因为 KL 是**站在真实分布 $P$ 的角度**看差异：

$$D_{KL}(P \| Q) = \mathbb{E}_{x \sim P}\left[\log \frac{P(x)}{Q(x)}\right]$$

- $P$ 认为重要的事件 → 权重大，差异被重点考虑
- $P$ 认为不重要的事件 → 权重小，即使有差异也无关紧要

> 按真实分布 $P$ 采样，看模型分布 $Q$ 平均偏离真实分布多少。

---

### 3.3 KL 的核心性质

1. **非负**：$D_{KL}(P \| Q) \geq 0$，仅当 $P = Q$ 时为 0（Gibbs 不等式）
2. **非对称**：$D_{KL}(P \| Q) \neq D_{KL}(Q \| P)$ → **不是距离**
3. **可能无界**：$Q(x) \to 0$ 而 $P(x) > 0$ 时，$D_{KL} \to \infty$

---

## 4. 交叉熵、熵、KL 三者的关系：从公式推

**最重要的公式**：

$$H(P, Q) = H(P) + D_{KL}(P \| Q)$$

下面从 KL 公式直接推。

---

### 4.1 推导

从 KL 出发：

$$D_{KL}(P \| Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$$

利用 $\log \frac{a}{b} = \log a - \log b$：

$$D_{KL}(P \| Q) = \sum_x P(x) [\log P(x) - \log Q(x)]$$

拆开：

$$D_{KL}(P \| Q) = \sum_x P(x) \log P(x) - \sum_x P(x) \log Q(x)$$

注意：
- $\sum_x P(x) \log P(x) = -H(P)$
- $-\sum_x P(x) \log Q(x) = H(P, Q)$

代回去：

$$D_{KL}(P \| Q) = -H(P) + H(P, Q)$$

移项：

$$\boxed{H(P, Q) = H(P) + D_{KL}(P \| Q)}$$

---

### 4.2 这个关系的含义

```text
交叉熵 = 真实分布本身的不确定性 + 模型分布和真实分布的差距
```

- $H(P)$：真实分布自己有多难预测（模型无法改变）
- $D_{KL}(P \| Q)$：模型 $Q$ 额外带来的错误（模型唯一能改的）
- $H(P, Q)$：用模型 $Q$ 预测真实分布 $P$ 的总代价

---

### 4.3 为什么"最小化交叉熵等价于最小化 KL"？

训练数据固定时，真实分布 $P$ 固定，$H(P)$ 是常数。

$$\min_Q H(P, Q) = \min_Q [H(P) + D_{KL}(P \| Q)] = \min_Q D_{KL}(P \| Q)$$

```text
最小化交叉熵 = 让模型分布 Q 尽量接近真实分布 P。
```

这就是 LM 训练的数学基础。

---

## 5. KL 为什么有方向性？

两个方向：

$$D_{KL}(P \| Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$$

$$D_{KL}(Q \| P) = \sum_x Q(x) \log \frac{Q(x)}{P(x)}$$

权重不同：**前向用 $P(x)$ 加权，反向用 $Q(x)$ 加权**。

---

### 5.1 前向 KL：$D_{KL}(P \| Q)$ — Mode-covering

按 $P(x)$ 加权，重点关心：

```text
P 认为重要的地方，Q 有没有覆盖。
```

如果 $P(x) > 0$ 但 $Q(x) \approx 0$：

$$\frac{P(x)}{Q(x)} \to \infty \quad \Rightarrow \quad \log \frac{P(x)}{Q(x)} \to \infty$$

→ KL 爆炸。

**结论**：前向 KL 倾向于覆盖 $P$ 的所有可能性，宁可"涂得宽"也不漏掉。

---

### 5.2 反向 KL：$D_{KL}(Q \| P)$ — Mode-seeking

按 $Q(x)$ 加权，重点关心：

```text
Q 自己放了概率的地方，在 P 里面是不是也合理。
```

如果 $Q(x) > 0$ 但 $P(x) \approx 0$：

$$\frac{Q(x)}{P(x)} \to \infty$$

→ KL 爆炸。

**结论**：反向 KL 不敢把概率放到 $P$ 认为不可能的地方，倾向于"龟缩"到 $P$ 的高概率区。

---

### 5.3 数学例子看方向性

真实分布 $P$ 有两个等概率模式：$P(A) = P(B) = 0.5$。

模型选择 1：完美覆盖 $Q(A) = Q(B) = 0.5$
$$D_{KL}(P \| Q) = 0$$

模型选择 2：只覆盖一个 $Q(A) = 1, Q(B) = 0$

前向 KL：
$$D_{KL}(P \| Q) = 0.5 \log \frac{0.5}{1} + 0.5 \log \frac{0.5}{0} \to \infty$$

→ 前向 KL **极度讨厌漏掉模式**。

反向 KL：
$$D_{KL}(Q \| P) = 1 \log \frac{1}{0.5} + 0 \log \frac{0}{0.5} = \log 2$$

→ 反向 KL 对"只选一个模式"惩罚有限，所以 **mode-seeking**。

---

### 5.4 LLM 中怎么选？

- **预训练 / SFT（CLM 训练）**：等价于最小化 $D_{KL}(P_{\text{data}} \| P_{\text{model}})$（前向 KL）
- **RLHF 的 KL 约束**：$D_{KL}(\pi_\theta \| \pi_{\text{ref}})$（反向 KL，让 policy 不偏离 SFT）
- **生成式蒸馏**（MiniLLM）：用反向 KL，避免学生在教师认为不可能的地方分配概率

## 6. PPL（困惑度）：为什么是交叉熵的指数？

LM 训练时，一个序列的平均负对数似然：

$$H = -\frac{1}{N} \sum_{i=1}^N \log P(x_i | x_{<i})$$

这就是平均交叉熵。**PPL 定义**：

$$\text{PPL} = \exp(H) = \exp\left(-\frac{1}{N} \sum_{i=1}^N \log P(x_i | x_{<i})\right)$$

---

### 6.1 为什么要取指数？

利用 $\exp(\frac{1}{N} \sum \log a_i) = (\prod a_i)^{1/N}$：

$$\text{PPL} = \left(\prod_{i=1}^N \frac{1}{p_i}\right)^{1/N}, \quad p_i = P(x_i | x_{<i})$$

所以 PPL = **模型给真实 token 概率倒数的几何平均**。

---

### 6.2 PPL = "平均在几个候选词里选"

假设模型每步都给真实 token 同样的概率 $p_i = p$：

$$\text{PPL} = \left(\frac{1}{p^N}\right)^{1/N} = \frac{1}{p}$$

| 模型给真实 token 的平均概率 | PPL | 直观解释 |
|---:|---:|---|
| 1.0 | 1 | 完美预测 |
| 0.5 | 2 | 平均在 2 个等可能里猜 |
| 0.1 | 10 | 平均在 10 个候选里猜 |
| 0.01 | 100 | 平均在 100 个候选里猜 |

```text
PPL ≈ 1 / (真实 token 的平均概率)
更准确地说，是概率倒数的几何平均。
```

---

### 6.3 LM 比较 PPL 时的注意事项

1. **必须同 tokenizer / 同测试集**：词表不同则 PPL 不可比
2. **PPL 低不一定生成好**：PPL 只衡量似然，不衡量事实性、有用性
3. **跨语言不可直接比**：中文 token 通常比英文 token 信息密度高，PPL 数值不同

## 7. JS 散度（顺带补充）

$$D_{JS}(P \| Q) = \frac{1}{2} D_{KL}(P \| M) + \frac{1}{2} D_{KL}(Q \| M), \quad M = \frac{P + Q}{2}$$

**性质**：
- **对称**：$D_{JS}(P \| Q) = D_{JS}(Q \| P)$
- **有界**：$0 \leq D_{JS} \leq \log 2$
- 平方根 $\sqrt{D_{JS}}$ 是合法距离

**用在哪**：GAN 原始目标用 JS 散度，但训练不稳定（梯度消失），后来被 Wasserstein 距离替代。

---

## 8. 互信息（Mutual Information）

$$I(X; Y) = D_{KL}(P(X, Y) \| P(X) P(Y)) = H(X) - H(X | Y)$$

**含义**：
- 衡量两个随机变量的依赖程度
- 独立时 $I(X; Y) = 0$
- 完全依赖时 $I(X; Y) = H(X)$

**LLM 应用**：
- 信息瓶颈理论
- 对比学习目标（InfoNCE）是 MI 的下界

---

## 9. MLE 与 MAP

**MLE（最大似然估计）**：

$$\hat\theta_{\text{MLE}} = \arg\max_\theta P(D | \theta) = \arg\max_\theta \prod_i P(x_i | \theta)$$

对应 LLM 训练：最大化训练数据的对数似然 → 最小化交叉熵。

**MAP（最大后验估计）**：

$$\hat\theta_{\text{MAP}} = \arg\max_\theta P(\theta | D) = \arg\max_\theta P(D | \theta) P(\theta)$$

**关系**：
- MAP = MLE + 先验
- 高斯先验 ↔ L2 正则（Weight Decay）
- 拉普拉斯先验 ↔ L1 正则

## 10. 最简数学记忆法

```text
熵：
  自己用自己预测自己
  H(P) = E_P[-log P(x)]

交叉熵：
  用 Q 去预测 P
  H(P,Q) = E_P[-log Q(x)]

KL：
  用 Q 代替 P 多出来的代价
  KL(P||Q) = E_P[log P(x) - log Q(x)]

PPL：
  交叉熵取指数
  PPL = exp(H)
```

**最关键的一组关系**：

$$\begin{aligned}
D_{KL}(P \| Q) &= \sum_x P(x) \log P(x) - \sum_x P(x) \log Q(x) \\
&= -H(P) + H(P, Q)
\end{aligned}$$

$$\boxed{H(P, Q) = H(P) + D_{KL}(P \| Q)}$$

这就是熵、交叉熵、KL 散度三者的数学核心。

## 🎯 高频面试追问

1. **为什么 LLM 用 CE 而不是 MSE**？分类任务，MSE 梯度在饱和区消失；CE 与 softmax 配合，梯度 $q - p$（softmax 输出 - 真实标签），简洁稳定。

2. **Softmax + CE 的梯度为什么这么简洁**？$\frac{\partial L}{\partial z_i} = q_i - p_i$，softmax 的导数与 log 的导数恰好相消。PyTorch 的 `CrossEntropyLoss` 接收 logits 就是为了用 log-sum-exp 稳定算这一步。

3. **Label Smoothing 怎么改变交叉熵**？把 one-hot 改成 $(1 - \epsilon) \cdot \text{onehot} + \epsilon / K$，等价于在 CE 中增加了一个与均匀分布的 KL 项，缓解过度自信。

4. **温度 $T$ 如何影响 softmax**？$P_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$。$T \to 0$ 接近 argmax，$T \to \infty$ 接近均匀。蒸馏中用大 $T$ 暴露更多"暗知识"。

5. **RLHF 中的 KL 是前向还是反向**？$D_{KL}(\pi_\theta \| \pi_{\text{ref}})$ 是**反向 KL**（policy 在前），所以 policy 倾向 mode-seeking——不敢偏离 SFT 模型分布太远，这正是我们想要的"约束"。
