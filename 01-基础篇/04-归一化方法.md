# 归一化方法

> 归一化层的对比是面试必考，Transformer 的稳定性主要靠它。

---

## Q1: BatchNorm vs LayerNorm vs RMSNorm vs GroupNorm 的区别？

**答**：归一化的差别本质是**沿哪个维度计算均值/方差**。

设输入张量 $X \in \mathbb{R}^{B \times L \times D}$（batch × 序列 × 特征）：

| 归一化 | 沿哪维统计 | 公式 | 典型场景 |
|--------|----------|------|---------|
| BatchNorm | 跨 batch（每个特征独立） | $\mu, \sigma$ 在 $(B, L)$ 维 | CNN |
| LayerNorm | 跨特征（每个样本独立） | $\mu, \sigma$ 在 $D$ 维 | Transformer |
| RMSNorm | 跨特征，**只用 RMS 不减均值** | $\sigma$ 在 $D$ 维 | LLaMA、Qwen 等 |
| GroupNorm | 把 $D$ 分成 G 组分别归一 | $\mu, \sigma$ 在每组 | CNN、小 batch |

**LayerNorm 公式**：
$$y = \gamma \cdot \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta$$

**RMSNorm 公式**：
$$y = \gamma \cdot \frac{x}{\sqrt{\frac{1}{D}\sum x_i^2 + \epsilon}}$$

---

## Q2: 为什么 Transformer 不用 BatchNorm？

**答**：
1. **序列长度可变**：BN 需要 batch 维统计稳定，而 NLP 中序列长度、padding 让统计含噪。
2. **小 batch 训练**：LLM 微调常用小 batch，BN 统计不可靠。
3. **推理 / 训练不一致**：BN 推理用 running stats，训练用 batch stats，分布漂移影响生成。
4. **自回归推理**：解码时 batch=1 是常态，BN 几乎不可用。

LayerNorm 是 per-sample 的，完全避开以上问题。

---

## Q3: RMSNorm 相比 LayerNorm 省了什么？为什么有效？

**答**：
**省了**：
1. **均值计算**（$\mu$）
2. **减均值操作**
3. **bias 参数 $\beta$**（一般也省略）

**计算量**：约省 7-15% 归一化层时间。

**为什么效果不降反升**：
- LayerNorm 的"re-centering"（减均值）作用其实有限，主要贡献来自"re-scaling"。
- 论文（Zhang & Sennrich, 2019）实验表明等效甚至略好。
- **LLaMA / Qwen / Mistral / DeepSeek 全用 RMSNorm**，已成为 LLM 事实标准。

## Q4: Pre-Norm vs Post-Norm 的区别？

**答**：

**Post-Norm**（原始 Transformer）：
```
x = LayerNorm(x + Sublayer(x))
```

**Pre-Norm**（现代 LLM）：
```
x = x + Sublayer(LayerNorm(x))
```

| 维度 | Post-Norm | Pre-Norm |
|------|-----------|----------|
| 训练稳定性 | 差，深层难训 | 好 |
| 是否需要 Warmup | 强依赖 | 弱依赖 |
| 表达能力 | 略强 | 略弱 |
| 现代 LLM | 几乎不用 | 全用 |

**Pre-Norm 为什么更稳**：
- 残差通路**未被 LN 切断**，梯度可以直接反传。
- 深层（>100）训练时 Pre-Norm 几乎是唯一选择。
- 代价：表示空间可能"被残差稀释"，效果略低于 Post-Norm（同等深度），但稳定性的收益远大于此。

## Q5: DeepNorm 是什么？解决了什么问题？

**答**：
- **背景**：千层 Transformer（如 1000 层）即使 Pre-Norm 也难训。
- **思路**：Post-Norm 表达力强但不稳，能否找个折中？
- **DeepNorm**（Microsoft, 2022）：
$$x = \text{LayerNorm}(\alpha x + \text{Sublayer}(x))$$
- 对残差路径乘缩放因子 $\alpha > 1$，并对部分参数缩小初始化 $\beta$。
- 推导出最优 $\alpha = (2N)^{1/4}$，$\beta = (8N)^{-1/4}$（N 是层数）。
- 成功训练了 1000 层 Transformer。
- 实际应用：GLM-130B、ChatGLM 等采用。

## Q6: 归一化层放在残差里面还是外面？（Pre vs Post 实现细节）

**答**：

**经典 Post-Norm**（"Attention is all you need"）：
```python
def block(x):
    x = norm(x + attention(x))      # 加完做 norm
    x = norm(x + ffn(x))
    return x
```

**Pre-Norm**（LLaMA/GPT 风格）：
```python
def block(x):
    x = x + attention(norm(x))      # 先 norm 再算
    x = x + ffn(norm(x))
    return x
```

**Sandwich Norm**（GLM 等）：
```python
def block(x):
    x = x + norm(attention(norm(x)))   # 两侧都 norm
    x = x + norm(ffn(norm(x)))
    return x
```

---

## Q7: 归一化前后的最后还需要一层 LN 吗？

**答**：
- **Pre-Norm 架构**：通常在所有 Block 之后**再加一层 final LN**，否则最后一层残差累加的输出方差很大。
- LLaMA 在 `embedding → N 个 block → final RMSNorm → lm_head` 这样的结构。
- Post-Norm 不需要 final LN（最后一层 LN 已经是输出归一化）。

## 🎯 高频追问

1. **LayerNorm 的 $\gamma$ 和 $\beta$ 有什么作用**？还原归一化前的表达能力（仿射变换），$\gamma$ 初始为 1，$\beta$ 初始为 0。
2. **RMSNorm 的可训练参数有几个**？只有 $\gamma$（$D$ 维），通常没有 $\beta$。
3. **为什么 Pre-Norm 训练后期效果稍差**？深层时残差通路占主导，相当于浅层网络的有效深度；可通过加宽或多训缓解。
4. **训练 / 推理时 LN 的统计有差别吗**？无差别，永远 per-sample 计算。这是 LN 比 BN 优雅的关键。
