## Q1: 熵的公式是什么？为什么它能表示"不确定性"？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

$$H(P) = -\sum_x P(x) \log P(x) = \mathbb{E}_{x \sim P}[-\log P(x)]$$

拆两步理解：
- $-\log P(x)$ 是事件 $x$ 的"信息量/惊讶程度"——概率越小越意外，信息量越大
- 乘 $P(x)$ 再求和 = 按概率加权平均 = 对信息量求期望

所以熵 = 整个分布的平均信息量。分布越均匀越难猜，熵越大（均匀分布熵最大，确定分布熵为 0）。

**追问：为什么均匀分布熵最大？** 直觉"啥都可能"最难预测；数学上约束 $\sum P(x)=1$ 下用拉格朗日乘子可证 $H$ 在 $P(x)=1/K$ 处取最大值 $\log K$。

## Q2: 交叉熵和熵的区别？为什么交叉熵能当 loss？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

$$H(P,Q) = -\sum_x P(x)\log Q(x)$$

和熵唯一区别：熵用 $\log P(x)$（自己预测自己），交叉熵用 $\log Q(x)$（用模型 $Q$ 预测真实 $P$）。

能当 loss：它衡量"模型在真实数据上的平均惊讶程度"——模型给真实事件概率越高，$-\log Q$ 越小，loss 越小。最小化它就是把真实标签的预测概率推高。

**追问：LLM 里交叉熵为什么退化成 $-\log Q(x_{真实})$？** 真实标签是 one-hot，只有真实 token 的 $P=1$，其余为 0，求和后只剩 $-\log Q(\text{真实 token})$。

## Q3: KL 散度的公式、3 个核心性质？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

$$D_{KL}(P\|Q) = \sum_x P(x)\log\frac{P(x)}{Q(x)} = \mathbb{E}_{x\sim P}\left[\log\frac{P(x)}{Q(x)}\right]$$

三个性质：
1. **非负**：$\geq 0$，仅 $P=Q$ 时为 0（Gibbs 不等式）
2. **非对称**：$D_{KL}(P\|Q)\neq D_{KL}(Q\|P)$ → 不是距离
3. **可能无界**：$Q(x)\to 0$ 而 $P(x)>0$ 时趋于 $\infty$

直觉：站在真实分布 $P$ 的角度，"用 $Q$ 代替 $P$ 平均多付出的代价"。

## Q4: 推导交叉熵、熵、KL 三者的关系（白板题）
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥🔥

$$\boxed{H(P,Q) = H(P) + D_{KL}(P\|Q)}$$

推导：
$$D_{KL}(P\|Q) = \sum_x P(x)[\log P(x) - \log Q(x)] = \underbrace{\sum P\log P}_{-H(P)} - \underbrace{\sum P\log Q}_{-H(P,Q)} = H(P,Q) - H(P)$$

含义：交叉熵 = 真实分布本身的不确定性 $H(P)$ + 模型与真实的差距 $D_{KL}$。

**追问：为什么"最小化交叉熵 = 最小化 KL"？** 训练数据固定 → $P$ 固定 → $H(P)$ 是常数 → $\min_Q H(P,Q) = \min_Q D_{KL}(P\|Q)$。这是 LM 训练的数学基础。

## Q5: KL 的方向性——前向 KL 和反向 KL 有什么区别？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥

| | 前向 $D_{KL}(P\|Q)$ | 反向 $D_{KL}(Q\|P)$ |
|---|---|---|
| 加权 | 按 $P(x)$ | 按 $Q(x)$ |
| 行为 | mode-covering（覆盖所有模式） | mode-seeking（聚焦单一模式） |
| 惩罚 | $P>0$ 而 $Q\approx 0$ 时爆炸（不敢漏） | $Q>0$ 而 $P\approx 0$ 时爆炸（不敢乱放） |

**LLM 中**：
- 预训练/SFT（CLM）≈ 最小化前向 KL $D_{KL}(P_{data}\|P_{model})$
- RLHF 的 KL 约束 $D_{KL}(\pi_\theta\|\pi_{ref})$ 是反向 KL，让 policy 不偏离 SFT

## Q6: PPL（困惑度）是什么？和交叉熵什么关系？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

$$\text{PPL} = \exp(H) = \exp\left(-\frac{1}{N}\sum_i \log Q(x_i\mid x_{<i})\right) = \left(\prod_i \frac{1}{q_i}\right)^{1/N}$$

PPL = 平均交叉熵取指数 = 模型给真实 token 概率倒数的**几何平均**。

直观：可理解为"模型平均在多少个等可能候选里猜"——PPL=10 相当于每步在 10 个候选里挑。

**追问：比较两个模型 PPL 要注意什么？** ① 必须同 tokenizer 同测试集；② PPL 低 ≠ 生成质量好（只衡量似然）；③ 跨语言不可直接比。

## Q7: 为什么 LLM 用交叉熵而不是 MSE？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

- LLM 是分类任务（预测词表上的分布），不是回归
- MSE 配 softmax 时，输出饱和区梯度趋零，学得慢
- CE 配 softmax，梯度是 $q_i - p_i$（softmax 输出 - 真实标签），形式简洁、不饱和、训练稳定

**追问：为什么 softmax+CE 梯度这么简洁？** softmax 的导数和 log 的导数恰好相消，最终 $\frac{\partial L}{\partial z_i} = q_i - p_i$。

## Q8: 温度系数 $T$ 怎么影响 softmax？蒸馏为什么用大 $T$？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

$$Q_i = \frac{\exp(z_i/T)}{\sum_j \exp(z_j/T)}$$

- $T\to 0$：分布变尖，接近 argmax（确定）
- $T\to\infty$：分布变平，接近均匀
- $T=1$：原始 softmax

**蒸馏用大 $T$**：放大非最大类的相对概率，暴露教师的"暗知识"（哪些错误答案更接近正确），让学生学到类别间相似结构。

## Q9: Label Smoothing 是什么？从 KL 角度怎么理解？
> 难度 ⭐⭐ ｜ 高频 🔥

把 one-hot 标签 $[0,1,0]$ 改成 $(1-\epsilon)\cdot\text{onehot} + \epsilon/K$（$\epsilon$ 平滑系数，$K$ 类别数）。

从 KL 角度：等价于在 CE loss 上加一个"与均匀分布的 KL 项"，**惩罚模型过度自信**（不让某 logit 无限大），提升泛化、改善校准。

---

## Q10: MLE 和 MAP 的区别？和 L1/L2 正则什么关系？
> 难度 ⭐⭐ ｜ 高频 🔥

- **MLE**：$\arg\max_\theta P(D\mid\theta)$，只看数据似然
- **MAP**：$\arg\max_\theta P(D\mid\theta)P(\theta)$，多了参数先验

关系：
- MAP 加**高斯先验** ↔ L2 正则（weight decay）
- MAP 加**拉普拉斯先验** ↔ L1 正则（稀疏）

LM 训练的最大似然目标就是 MLE。
