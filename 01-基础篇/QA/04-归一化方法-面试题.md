## Q1: BatchNorm / LayerNorm / RMSNorm 的区别？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

差别本质是**沿哪个维度算均值/方差**。设输入 $X \in \mathbb{R}^{B\times L\times D}$：

| 方法 | 沿哪维统计 | 直觉 |
|---|---|---|
| **BatchNorm** | 跨 batch（$B,L$ 维，每个特征独立） | "这个特征在整个 batch 里的统计" |
| **LayerNorm** | 跨特征（$D$ 维，每个样本独立） | "这个样本所有特征的统计" |
| **RMSNorm** | 跨特征（只算 RMS，不减均值） | LayerNorm 的简化版 |

---

## Q2: 为什么 Transformer 用 LayerNorm 不用 BatchNorm？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

BN 在 NLP 上几乎不可用：
1. **序列长度可变 + padding**：BN 统计被 padding 污染
2. **训练/推理不一致**：BN 推理用 running stats，分布漂移影响生成
3. **小 batch 不可靠**：LLM 微调常用小 batch
4. **自回归推理**：解码时 batch=1，BN 几乎不能用

LayerNorm 是 per-sample 计算，完全避开以上问题（训练/推理永远一致）。

---

## Q3: RMSNorm 相比 LayerNorm 省了什么？为什么效果不降？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

LayerNorm 做两件事：**减均值（re-centering）+ 除标准差（re-scaling）**。RMSNorm 只做 re-scaling：

$$y = \gamma \cdot \frac{x}{\sqrt{\frac{1}{D}\sum x_i^2 + \epsilon}}$$

省了：① 均值计算 ② 减均值操作 ③ bias 参数 $\beta$。

**计算省 7-15%，效果等效或略好**——研究发现 LN 主要靠 re-scaling 起作用，re-centering 影响很小。LLaMA/Qwen/Mistral/DeepSeek 全用 RMSNorm。

## Q4: Pre-Norm 和 Post-Norm 的区别？为什么现代 LLM 都用 Pre-Norm？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥🔥

- **Post-Norm**（原版）：`y = LayerNorm(x + Sublayer(x))`
- **Pre-Norm**（现代）：`y = x + Sublayer(LayerNorm(x))`

关键看残差路径的梯度：
- Post-Norm：残差路径有 LN，梯度被 LN 雅可比"截断"
- **Pre-Norm：残差路径是恒等（梯度有"+I"直通），深层稳定**

| | Pre-Norm | Post-Norm |
|---|---|---|
| 训练稳定性 | 好 | 差（深层难训） |
| Warmup 依赖 | 弱 | 强 |
| 表达能力 | 略弱 | 略强 |

**追问：Pre-Norm 缺点？** 深层时残差路径占主导，等效深度变浅、表达力略降。但稳定性收益远大于此。

## Q5: 为什么 LayerNorm 要有可训练参数 $\gamma, \beta$？
> 难度 ⭐⭐ ｜ 高频 🔥

$$y = \gamma \cdot \frac{x-\mu}{\sqrt{\sigma^2+\epsilon}} + \beta$$

归一化强制把分布拉到 0 均值单位方差，可能"过度"——$\gamma$（缩放）和 $\beta$（平移）让模型**还原表达能力**。$\gamma$ 初值 1，$\beta$ 初值 0（初始等于恒等映射）。

**追问：RMSNorm 有 $\beta$ 吗？** 通常没有，只有 $\gamma$。

---

## Q6: 千层 Transformer 怎么稳定训练？DeepNorm 是什么？
> 难度 ⭐⭐⭐⭐ ｜ 高频 🔥

Pre-Norm 在 100+ 层很稳，但 1000 层仍会发散。

**DeepNorm**（MS 2022）：对残差路径乘缩放因子 $\alpha>1$，并对部分参数缩小初始化：

$$y = \text{LayerNorm}(\alpha \cdot x + \text{Sublayer}(x))$$

最优 $\alpha = (2N)^{1/4}$（$N$ 是层数）。成功训练 1000 层 Transformer（GLM-130B 等采用）。

---

## Q7: Pre-Norm 架构最后为什么要加一层 Final Norm？
> 难度 ⭐⭐ ｜ 高频 🔥

Pre-Norm 中残差路径不被归一化，**最后输出方差会随层数累积变大**。所以在所有 block 之后加一层 final RMSNorm：

```
embedding → N × block → final RMSNorm → lm_head
```

否则 lm_head 接收的激活方差过大，影响输出。
