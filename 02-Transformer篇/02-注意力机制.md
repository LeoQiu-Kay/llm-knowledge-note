> 必考！注意力是 Transformer 的灵魂，公式、动机、复杂度都要烂熟。

## Q1: Scaled Dot-Product Attention 公式默写？

**答**：
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V$$

**维度推导**：
- $Q \in \mathbb{R}^{n \times d_k}$，$K \in \mathbb{R}^{n \times d_k}$，$V \in \mathbb{R}^{n \times d_v}$
- $QK^T \in \mathbb{R}^{n \times n}$（每个位置对所有位置的相似度）
- softmax 沿最后一维归一化（每行和为 1）
- 与 V 相乘得 $\mathbb{R}^{n \times d_v}$

**伪代码**：
```python
def attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-1, -2) / math.sqrt(d_k)   # [B,H,L,L]
    if mask is not None:
        scores.masked_fill_(mask, float('-inf'))
    attn = scores.softmax(dim=-1)
    return attn @ V
```

## Q2: 为什么要除以 $\sqrt{d_k}$？不除会怎样？

**答**：
**直观回答**：当 $d_k$ 很大时，$QK^T$ 的方差变大，softmax 进入饱和区，梯度变小，训练困难。

**数学推导**：
- 假设 $q, k$ 各分量独立同分布，$\mathbb{E}[q_i]=\mathbb{E}[k_i]=0$，$\text{Var}[q_i]=\text{Var}[k_i]=1$。
- $q \cdot k = \sum_{i=1}^{d_k} q_i k_i$
- $\mathbb{E}[q \cdot k] = 0$
- $\text{Var}[q \cdot k] = d_k$（独立项方差相加）
- 除以 $\sqrt{d_k}$ 后方差归一到 1，softmax 输入分布稳定。

**不除的后果**：
- $d_k = 64$ 时，方差为 64，softmax 输入跨度约 $\pm 16$，输出几乎是 one-hot。
- one-hot 输出 → 梯度对最大项非常小（饱和）→ 难以训练。

**追问**：为什么是 $\sqrt{d_k}$ 而不是 $d_k$？
- 标准差是 $\sqrt{d_k}$，除标准差才能归一化方差到 1。

## Q3: Q、K、V 三个矩阵的物理意义？

**答**：
- **Query（查询）**：当前 token "我在找什么样的信息"。
- **Key（键）**：每个 token "我能提供什么样的信息"。
- **Value（值）**：实际被加权的内容。

**类比**：
- 像数据库查询。Q 是 SQL 查询，K 是索引，V 是真实数据。
- Q 和 K 算相似度（点积大 = 匹配），相似度作为权重对 V 加权求和。

**为什么要拆开 Q、K、V**：
- 三个独立线性变换提供更丰富的表达：找信息的方式 ≠ 被找的特征 ≠ 实际内容。
- 实验上共享会显著降低效果。
- Cross-Attention 中 Q 来自一处、K/V 来自另一处，这个设计也只能在拆开时实现。

## Q4: Self-Attention vs Cross-Attention 的区别？

**答**：
- **Self-Attention**：Q、K、V 都来自同一个序列（如 Encoder 内部、Decoder masked self-attn）。
- **Cross-Attention**：Q 来自一个序列，K、V 来自另一个序列（如 Encoder-Decoder 中，Q 来自 Decoder，K、V 来自 Encoder 输出）。

**Cross-Attention 的用途**：
- Encoder-Decoder 翻译/摘要：让 Decoder 在生成时"看到" Encoder 编码的源语言。
- 多模态：让文本 Q 看到图像 K、V（如 BLIP、Flamingo）。

## Q5: Multi-Head Attention 的动机？参数量怎么算？

**答**：
**动机**：
- 单头注意力只能关注一种"关系模式"。
- 多头允许在不同的子空间里学不同的关系（语法依赖、共指、长距离等）。
- 类比 CNN 的多通道。

**实现**：
$$\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O$$
$$\text{head}_i = \text{Attention}(QW^Q_i, KW^K_i, VW^V_i)$$

**维度**：
- 总 hidden 维 $d$，头数 $h$，每头维度 $d_k = d_v = d / h$。
- 例如 $d=4096, h=32$ → $d_k=128$。

**参数量**：
- $W^Q, W^K, W^V$ 各 $d \times d$，$W^O$ 也是 $d \times d$
- 总参数：$4d^2$
- 与单头维度 $d$ 的 attention 参数量相同（巧妙！）

## Q6: 多头之间是否共享参数？头之间学到了什么？

**答**：
**参数共享**：
- 不同头**完全独立的 $W^Q_i, W^K_i, W^V_i$**，不共享。
- 实现上通常合并成一个大矩阵 $W^Q \in \mathbb{R}^{d \times d}$ 然后 reshape，但语义上是独立的。

**头学到的模式**（论文分析）：
- 句法关系：主谓、动宾
- 共指消解
- 位置相邻关系
- 长距离依赖
- 也有"懒头"什么都没学，可被剪枝（论文 "Are Sixteen Heads Really Better than One?"）

**MQA/GQA 的洞察**：既然 K/V 头之间冗余，可以共享 K/V 而 Q 保持多头。

## Q7: Self-Attention 的时间复杂度？为什么是 $O(n^2)$？

**答**：
- $QK^T$：$\mathbb{R}^{n \times d} \times \mathbb{R}^{d \times n} \to \mathbb{R}^{n \times n}$，复杂度 $O(n^2 d)$。
- softmax：$O(n^2)$。
- 与 V 相乘：$\mathbb{R}^{n \times n} \times \mathbb{R}^{n \times d}$，复杂度 $O(n^2 d)$。
- **总复杂度**：$O(n^2 d)$，序列长度 n 平方。

**对比 FFN**：$O(n d^2)$（线性于 n）

**何时 attention 主导**：
- 当 $n > d$ 时，attention 主导。
- LLaMA-7B：$d=4096$，序列长 $n=4k$ 时勉强 attention 占主导，更长（32K、128K）时彻底 attention 主导。

**显存复杂度**：$O(n^2)$（attention 矩阵本身），是长上下文的瓶颈 → FlashAttention 不显式实例化这个矩阵。

## Q8: Attention 的反向传播？

**答**：
对 $\text{Attn} = \text{softmax}(S) V$，其中 $S = QK^T / \sqrt{d_k}$：

**关键梯度**：
1. $\partial L / \partial V = A^T \partial L / \partial \text{Out}$，其中 $A$ 是 softmax 后的注意力矩阵。
2. $\partial L / \partial A = \partial L / \partial \text{Out} \cdot V^T$
3. softmax 反传：$\partial L / \partial S_{ij} = A_{ij} (\partial L / \partial A_{ij} - \sum_k A_{ik} \partial L / \partial A_{ik})$
4. $\partial L / \partial Q = (\partial L / \partial S) K / \sqrt{d_k}$
5. $\partial L / \partial K = (\partial L / \partial S)^T Q / \sqrt{d_k}$

**实现关键**：
- softmax 的雅可比是密集矩阵，但其与梯度乘积可向量化实现。
- FlashAttention 在反向时重计算 $S$ 和 $A$（不存中间），节省显存。

## Q9: Attention 输出和 FFN 输出哪个贡献更大？

**答**：
- 一般认为 **FFN 是参数主体**：LLaMA 中 FFN 参数占 ~65%。
- **Attention 提供混合**：让 token 间交换信息。
- **FFN 提供变换**：在每个位置独立做非线性变换，可视为 key-value 存储器（"Transformer Feed-Forward Layers Are Key-Value Memories"）。
- 缺一不可：去掉 attention 等于禁止 token 通信；去掉 FFN 等于丢失大半参数。

## 🎯 高频追问

1. **Attention 矩阵的稀疏性如何**？训练后大部分注意力很稀疏（few-shot），少数稠密（CLS、最近 token）。
2. **能不能用 sigmoid 代替 softmax 做注意力**？可以（如 Apple 的工作），但主流仍是 softmax，因其"分配权重"语义更明确。
3. **为什么 attention 用点积而不用加性**？点积可用矩阵乘并行，加性（Bahdanau）需逐对计算，慢得多。论文还提到点积在 GPU 上更高效。
4. **温度怎么影响 attention**？softmax 输入除以温度 $T$，T 大 → 更平滑；T 小 → 更尖锐。$\sqrt{d_k}$ 实质就是温度的一种。
5. **head_dim 怎么选**？经验值 64 或 128，太小表达力不足，太大单头容易冗余。LLaMA-2/3 用 128。
