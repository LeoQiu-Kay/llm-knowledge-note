## Q1: 白板默写 Scaled Dot-Product Attention 公式，并解释每一步
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V$$

**五步拆解**（顺着图自下而上）：
1. **$QK^T$**：算 $n \times n$ 相似度矩阵，$(i,j)$ 位置 = $q_i \cdot k_j$
2. **除 $\sqrt{d_k}$**：归一化方差，防止 softmax 饱和
3. **Mask**（可选）：Decoder 上三角加 $-\infty$ 屏蔽未来
4. **softmax**：每行归一化成"和为 1 的权重"
5. **$\cdot V$**：用权重对 $V$ 做加权求和，输出 $n \times d_v$

**Q/K/V 类比数据库**：Q = "我要找什么"、K = "我有什么"、V = "实际内容"。

## Q2: 为什么要除以 $\sqrt{d_k}$？不除会怎样？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥🔥

**数学推导**：假设 $q, k$ 各分量独立、均值 0、方差 1：

$$q \cdot k = \sum_{i=1}^{d_k} q_i k_i, \quad \mathbb{E}[q\cdot k] = 0, \quad \text{Var}[q\cdot k] = d_k$$

$d_k = 64$ 时方差为 64，标准差约 8 → softmax 输入跨度约 $\pm 16$：

$$\text{softmax}([16, -16, \dots]) \approx \text{one-hot}$$

**后果**：
- 最大项概率 ≈ 1，其他 ≈ 0 → softmax 饱和
- 反向 softmax 的雅可比矩阵在饱和区接近 0 → **梯度消失**，训练不动

除以 $\sqrt{d_k}$ 把方差归一到 1 → softmax 输入跨度合理 → 训练稳定。

**追问：$\sqrt{d_k}$ 和"温度"什么关系？** 完全等价。$QK^T/T$ 中 $T = \sqrt{d_k}$ 就是温度。这是一个由维度决定的固定温度选择。

## Q3: 为什么 Q 和 K 用不同矩阵？共享一个会怎样？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥

**功能分离**：
- $W^Q$ 学的是"找信息的方式"（query 视角）
- $W^K$ 学的是"被找的特征"（key 视角）

二者天然不对称——"狗"问的是"主语是谁"，"咬"问的是"宾语是什么"。

**共享后果**：
- $QK^T = (XW)(XW)^T = XWW^TX^T$，是一个**对称矩阵**
- 对称 attention 意味着"i 关注 j" = "j 关注 i"——但语言里这显然不成立（动词关注主语 ≠ 主语关注动词）
- 实验：效果显著下降

**追问：那 V 为什么也独立？** V 是"实际被搬过来的内容"，与"如何检索"是完全不同的事，必须独立投影。

## Q4: Multi-Head Attention（MHA）的动机是什么？参数量为什么不变？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

**MHA**（Multi-Head Attention，多头注意力）：单头 attention 只能学一种"关系模式"，多头让模型在不同子空间学不同关系（类比 CNN 多通道）。

**实现**：把 $d$ 维拆成 $h$ 个 $d_k = d/h$ 维子空间，每个头独立算 attention，拼接后过 $W^O$：

$$\text{MultiHead} = \text{Concat}(\text{head}_1, \dots, \text{head}_h) \cdot W^O$$

**参数量**：$W^Q, W^K, W^V, W^O$ 每个都是 $d \times d$，总共 $4d^2$。

**巧妙之处**：和"单头维度 $d$ 的 attention"参数量完全相同！多头只是把同样的参数预算切成 $h$ 份并行使用。

**追问：head_dim 怎么选？** 经验 64 或 128。LLaMA-2/3 用 128。太小表达力弱；太大冗余、对长上下文外推不友好。

## Q5: 各个头分别学到了什么？
> 难度 ⭐⭐ ｜ 高频 🔥

论文（如 Voita et al. 2019、Clark et al. 2019）通过可视化和探针分析发现：

| 头类型 | 学到的模式 |
|---|---|
| 句法头 | 主谓、动宾依存关系 |
| 共指头 | 代词指向哪个名词 |
| 位置头 | 关注前一/前几个 token |
| 长程头 | 关注段首、特殊 token |
| "懒头" | 几乎没学东西，可剪枝 |

**应用**：head pruning 研究表明 30-50% 的头可剪掉，效果几乎无损 → 后续 MQA/GQA 的灵感来源之一。

## Q6: Attention 的计算和显存复杂度分别是多少？长序列瓶颈在哪？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥🔥

| | 复杂度 |
|---|---|
| 计算（$QK^T$ + $\cdot V$） | $O(n^2 d)$ |
| 显存（attention 矩阵 $n \times n$） | $O(n^2)$ |

**何时 attention 主导**：$n > d$ 时计算和显存都被 attention 吃掉。
- LLaMA-7B（$d = 4096$）：$n = 4K$ 边界、$n = 32K$ 完全 attention 主导

**长序列两个真实瓶颈**：
1. **显存**：$O(n^2)$ attention 矩阵装不下（128K 序列、FP16 → 32 GB 仅一个矩阵）
2. **HBM IO**：attention 矩阵在 HBM 和 SRAM 之间反复搬运 → memory-bound

**FlashAttention 解法**：分块计算 + 不实例化完整矩阵 + online softmax → 计算量不变（仍 $O(n^2 d)$），但 IO 从 $O(n^2)$ 降到 $O(n)$，实际墙钟时间 2-4 倍提速。

## Q7: 推理时 Attention 的形态有什么变化（KV Cache）？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

自回归生成时观察两个事实：
1. 历史 token 的 K/V 在生成过程中**不变**
2. 每生成一个新 token，只需要 1 个新 Q 与全部历史 K/V 算 attention

**KV Cache**：把每层每个头的历史 K/V 缓存在显存里，每步只算新 token 的 Q/K/V 并把 K/V 追加到 cache。

**复杂度**：
- 朴素重算：每步 $O(t^2 d)$，总生成 $O(T^3 d)$
- KV Cache：每步 $O(t d)$，总生成 $O(T^2 d)$

**代价**：KV Cache 占大量显存，随 $L \cdot t \cdot h \cdot d_h$ 线性增长 → 这就是 MQA/GQA/MLA 演进的根源。

## Q8: Self-Attention 和 Cross-Attention 的区别？Decoder-only LLM 有 Cross-Attention 吗？
> 难度 ⭐ ｜ 高频 🔥🔥

| | Q 来自 | K, V 来自 |
|---|---|---|
| Self-Attention | 同一序列 | 同一序列 |
| Cross-Attention | 序列 A（如 Decoder） | 序列 B（如 Encoder 顶部） |

**Cross-Attention** 是 Encoder-Decoder 架构（T5、原始 Transformer）的关键组件，让 Decoder 在生成每个 token 时能"看"完整的 Encoder 输出。

**Decoder-only LLM（GPT/LLaMA）只有 Self-Attention**，没有 Cross-Attention。需要"看输入"时，输入直接作为 prompt 拼在前面，由 Causal Self-Attention 处理。

## Q9: 能用 Sigmoid 或者 加性 Attention 替代 Softmax 点积吗？
> 难度 ⭐⭐⭐ ｜ 高频 🔥

**加性 Attention**（Bahdanau）：
$$\text{score}(q, k) = v^T \tanh(W_q q + W_k k)$$
- 理论可行，但每对 $(q, k)$ 都要逐对算，无法用矩阵乘并行 → 慢得多
- 早期 RNN+Attention 用，Transformer 起被点积取代

**Sigmoid Attention**（Apple 2024）：用 sigmoid 替代 softmax
- 每个权重独立 $\in [0, 1]$，不再归一化为概率分布
- 优点：避免 softmax 的"权重必须相互抑制"问题
- 实际效果接近 softmax，但生态主流仍是 softmax

**核心区别**：softmax 是"分配 100% 的注意力"，sigmoid 是"独立判断每个 token 是否相关"。语义不同。
