## Q1: Transformer 相比 RNN 解决了什么问题？代价是什么？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

**RNN 两大痛点**：
1. **串行训练**：必须沿时间步走，GPU 不能并行
2. **长程依赖**：信号沿时间衰减，远处信息丢失

**Transformer 两个核心动作**：
1. 用 Attention 让任意两个 token 直接通信，距离 $O(1)$
2. 全序列并行计算

**代价**：复杂度从 $O(n)$ 变 $O(n^2)$（每对 token 都要算相似度），$n$ 是序列长度。长序列下显存和算力都是瓶颈。

**追问：为什么"弱归纳偏置"反而是优点？** RNN 有时序、CNN 有局部性都是强归纳偏置——数据少时帮助大，数据多时反而限制模型。Transformer 几乎不假设结构 → scaling laws 才能成立。

## Q2: Encoder-only / Decoder-only / Encoder-Decoder 三种结构怎么区分？分别适合什么任务？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

按 **Attention 能看到什么** 划分：

| 类型 | Attention 视野 | 任务 | 代表 |
|---|---|---|---|
| Encoder-only | 全部（双向） | 理解（分类、抽取、检索） | BERT |
| Decoder-only | 只看过去（单向 + Causal Mask） | 生成 | GPT、LLaMA、Qwen |
| Encoder-Decoder | Enc 双向 + Dec 单向 + Cross-Attention | 翻译、摘要 | T5、原始 Transformer |

**Cross-Attention**：Q 来自 Decoder，K/V 来自 Encoder 顶部输出——把"源序列上下文"传给 Decoder。Decoder-only 没有这一层。

## Q3: 为什么现代 LLM 都是 Decoder-only？（灵魂题）
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥🔥

三个层面：

**1. 训练目标更高效**
- **CLM**（Causal LM）：每个位置都预测下一个 token → 数据利用率 100%
$$\mathcal{L}_{\text{CLM}} = -\sum_{t=1}^{N} \log P(x_t \mid x_{<t})$$
- **MLM**（BERT）：只对 15% 被 mask 的 token 算 loss → 数据利用率 15%

**2. Zero/Few-shot 强**
- GPT-3 证明 Decoder-only + scaling 在 in-context learning 上吊打 T5
- Causal mask + 任意长 prompt 天然支持 ICL

**3. 部署友好**
- 无 Cross-Attention，架构简洁
- KV Cache 直接 work（每生成一个 token 复用历史）
- TP / PP 切分简单

**追问：PrefixLM 是什么？** 输入部分双向、输出部分单向，介于 Enc-Dec 与 Decoder-only 之间，GLM 早期用过，后来回归 Decoder-only。

## Q4: Causal Mask 怎么实现？为什么用 $-\infty$ 不是 0？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

构造上三角 mask 矩阵 $M \in \mathbb{R}^{L \times L}$：

$$M_{i,j} = \begin{cases} 0, & j \leq i \\ -\infty, & j > i \end{cases}$$

加到 attention scores 上：

$$\text{scores}_{i,j} = \frac{q_i \cdot k_j}{\sqrt{d_k}} + M_{i,j}$$

softmax 后，$e^{-\infty} = 0$ → 未来位置权重为 0。

**为什么不是直接置 0？** softmax 前置 0 等价于 $e^0 = 1$，权重不会被屏蔽，反而成了显著的"看到未来"信号。必须在 softmax 之前用 $-\infty$（实现里通常用 `-1e9`）压死 logit。

**追问：推理时 KV Cache 阶段还需要 mask 吗？** 不需要。增量解码每步 Q 只有 1 个 token，需要看全部历史 K/V，mask 退化成"全部可见"，可以省去。

## Q5: 一个现代 Transformer Block 长什么样？为什么是这两个子层？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

**Pre-Norm 现代版**（LLaMA 风格）：

$$h' = h + \text{Attention}(\text{RMSNorm}(h))$$
$$h'' = h' + \text{FFN}(\text{RMSNorm}(h'))$$

**两个子层各司其职**：
- **Attention**：让 token 之间通信（混合信息）
- **FFN**：每个 token 独立做非线性变换（无 token 间通信）

**记忆口诀**：Attention 横向、FFN 纵向；缺一不可——只有 Attention 没有 FFN，模型退化为线性变换的堆叠（softmax 加权 + 线性投影都是线性）。

## Q6: Transformer 的参数主要在哪？算一下 LLaMA-7B 的构成
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥

LLaMA-7B：$d = 4096, N_{\text{layers}} = 32$。

| 模块 | 单 Block 参数 | 占比 |
|---|---|---|
| Attention（QKVO 共 4 个 $d\times d$） | $4d^2 \approx 67$M | ~33% |
| FFN（SwiGLU 3 个矩阵） | $\approx 8d^2 \approx 134$M | ~65% |
| Embedding（$\|V\|=32K$） | $\|V\|\cdot d\approx 130$M | (块外) |

**结论**：FFN 占 Block 参数 ~2/3，全模型参数 ~65%。所以：
- **MoE 优先稀疏化 FFN**（最大块）
- 大模型推理时 FFN 是主要计算 + 参数瓶颈

**追问：LM Head 和 Embedding 共享吗？** LLaMA 不共享（独立 $W_{\text{lm\_head}}$），GPT-2 / T5 共享。共享省参数但灵活性差。

## Q7: Attention 是 $O(n^2)$，长序列怎么办？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥🔥

业界主要四条路：

| 方向 | 思路 | 代表 |
|---|---|---|
| **IO 优化** | $O(n^2)$ 计算不变，但避免实例化 attention 矩阵 | **FlashAttention**（fused kernel + 分块 + 反向重算） |
| **稀疏注意力** | 让 attention 矩阵稀疏 | Sliding Window（Mistral）、Sparse Attention |
| **线性注意力** | 用 kernel trick 把复杂度降到 $O(n)$ | Linformer、Performer |
| **状态空间模型** | 替换 Attention | Mamba、RWKV |

**最实用是 FlashAttention**：精确等价于原始 Attention，无效果损失，单卡训练 16K 已经能跑。

## Q8: Transformer 为什么不能完全去掉 FFN？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥

Attention 本质上是**线性**操作：
- $\text{softmax}(QK^T/\sqrt{d_k})$ 产生权重
- 用权重对 $V$ 做线性组合
- 再过 $W^O$ 线性投影

整个 Attention 子层对 $V$ 来说是"加权求和 + 线性投影"。多层 Attention 堆叠 = 一个更大的线性算子（在固定 attention pattern 下）。

**没有 FFN 提供的非线性激活（GELU/SwiGLU），整个 Transformer 退化为线性模型**——表达力暴跌。

**追问：那 softmax 不是非线性吗？** softmax 是非线性，但它作用在"权重"上，不直接作用在特征向量上。所以仍需 FFN 给特征本身引入非线性。
