# Transformer 整体架构

> 把握全局：三大变体路线与因果掩码的核心思想。

---

## Q1: 画出完整的 Transformer 架构图？

**答**：原始 Transformer 是 Encoder-Decoder：

```
Input Tokens                       Output Tokens (shifted right)
    ↓                                       ↓
[Embedding + PE]                    [Embedding + PE]
    ↓                                       ↓
┌──────────────┐                    ┌────────────────────┐
│  Encoder ×N  │                    │   Decoder ×N       │
│              │                    │                    │
│ Multi-Head   │                    │ Masked MHA         │
│ Self-Attn    │                    │   (Causal)         │
│   ↓ + Res    │                    │   ↓ + Res          │
│   LN         │                    │   LN               │
│   ↓          │                    │   ↓                │
│ FFN          │       ────────→    │ Cross-Attn         │
│   ↓ + Res    │   (encoder kv)     │   ↓ + Res          │
│   LN         │                    │   LN               │
└──────────────┘                    │   ↓                │
                                    │ FFN                │
                                    │   ↓ + Res          │
                                    │   LN               │
                                    └────────────────────┘
                                              ↓
                                       Linear + Softmax
                                              ↓
                                     Next Token Probabilities
```

**核心组件**：
1. Token Embedding + Positional Encoding
2. Multi-Head Self-Attention（Encoder/Decoder 共用）
3. Cross-Attention（Decoder 特有，Q 来自 Decoder，K/V 来自 Encoder）
4. Position-wise FFN
5. 残差连接 + LayerNorm（Post-Norm 原始版）

## Q2: Encoder-only / Decoder-only / Encoder-Decoder 的区别和适用任务？

**答**：

| 类型 | 代表模型 | 注意力可见性 | 适用任务 |
|------|---------|------------|---------|
| Encoder-only | BERT、RoBERTa、DeBERTa | 双向 | 分类、抽取、句向量 |
| Decoder-only | GPT、LLaMA、Qwen | 单向（causal） | 生成（chat、续写、推理） |
| Encoder-Decoder | T5、BART、原始 Transformer | Enc 双向 + Dec 单向 + Cross | 翻译、摘要、序列变换 |

**关键差异**：
- **Encoder-only**：每个 token 能看到所有 token，适合理解任务，但不能直接生成。
- **Decoder-only**：每个 token 只能看到自己和之前的，天然适合自回归生成。
- **Encoder-Decoder**：分离的理解与生成阶段，灵活但参数和延迟翻倍。

## Q3: 为什么现在主流 LLM 都是 Decoder-only？

**答**：这是高频灵魂题，多个层面：

1. **零样本能力强**（最关键）：
   - GPT 系列证明 Decoder-only + scaling 在 zero/few-shot 上吊打 Encoder-Decoder（如 T5）。
   - 论文："What Language Model Architecture and Pretraining Objective Works Best for Zero-Shot Generalization?"（Wang et al., 2022）。

2. **训练目标统一**：
   - CLM 一个目标同时学到理解和生成，数据利用率高（每个 token 都贡献 loss）。
   - 而 MLM 只对 15% 的 token 计算 loss，效率低。

3. **架构更简单**：
   - 无 Cross-Attention，无 Encoder/Decoder 切分，部署、并行、KV Cache 都简单。

4. **In-Context Learning**：
   - Decoder-only 的 causal attention 天然支持任意长度的上下文 prompt，BERT 这类做不到。

5. **理论分析**：
   - 一些研究认为 causal mask 提供了"低秩偏置"，加上足够深度可以模拟双向注意力。

6. **历史路径依赖**：
   - GPT-3 成功后整个生态（数据、Tokenizer、训练框架）都向 Decoder-only 倾斜。

## Q4: 因果掩码（Causal Mask）的实现方式？

**答**：
**目的**：自回归生成时，位置 $i$ 不能看到位置 $> i$ 的信息（否则等于偷看答案）。

**实现**：构造上三角矩阵（不含对角），将上三角元素置为 $-\infty$，与 QK^T 相加，softmax 后这些位置权重为 0。

```python
# seq_len = L
mask = torch.triu(torch.ones(L, L), diagonal=1).bool()
scores = Q @ K.transpose(-1, -2) / math.sqrt(d_k)  # [B, H, L, L]
scores.masked_fill_(mask, float('-inf'))
attn = scores.softmax(dim=-1)
```

**优化**：
- FlashAttention 在 kernel 内直接处理 mask，无需显式构造矩阵。
- 推理阶段（KV Cache），每步 Q 只有 1 个 token，mask 退化为"看所有历史"，可直接省去。

## Q5: 自回归 vs 非自回归生成？

**答**：
- **自回归（AR）**：$P(y_1, y_2, \dots, y_n) = \prod P(y_t | y_{<t})$
  - 优点：质量高、训练目标和推理一致
  - 缺点：串行解码慢
- **非自回归（NAR）**：一次生成全部 $y$
  - 优点：并行快
  - 缺点：质量差（多模问题）、需要复杂技巧（迭代精化、长度预测）
- **当前 LLM 全是 AR**，靠 KV Cache、投机解码等优化加速。

## Q6: Transformer 与 RNN/CNN 的本质区别？

**答**：

| 维度 | RNN/LSTM | CNN | Transformer |
|------|----------|-----|-------------|
| 长程依赖 | 衰减 | 受感受野限制 | 直接 $O(1)$ 跨距访问 |
| 并行性 | 串行（沿时间） | 并行 | 完全并行 |
| 计算复杂度 | $O(n d^2)$ | $O(k n d^2)$ | $O(n^2 d)$ |
| 归纳偏置 | 时序、局部 | 局部 + 平移不变 | 弱（靠数据学） |

**Transformer 的核心优势**：
1. 直接建模任意距离的依赖，无衰减
2. 训练时完全并行（不像 RNN 时间步串行）
3. 弱归纳偏置 + 大数据 = scaling laws 友好

**代价**：$O(n^2)$ 复杂度（长序列瓶颈）→ 催生 FlashAttention 等优化。

## Q7: Encoder 的 Multi-Head Self-Attention vs Decoder 的 Masked Self-Attention 实现差别？

**答**：唯一差别就是**是否加 causal mask**。
- Encoder 的 self-attention：每个位置能看到所有位置。
- Decoder 的 self-attention：每个位置只能看到自己和之前。

**Cross-Attention** 则是 Q 来自 Decoder，K/V 来自 Encoder 输出，不需要 causal mask（要看全文）。

## 🎯 高频追问

1. **BERT 时代为什么 Encoder-only 是主流**？当时主流任务是分类/抽取，pretraining + finetune 范式上 MLM 更适合理解任务。
2. **为什么 Transformer 没用 RNN/CNN**？解决长程依赖 + 完全并行训练。
3. **Encoder-Decoder 还有存在价值吗**？翻译、摘要等"输入输出明显分离"的任务仍有优势；但通用对话 Decoder-only 完胜。
4. **PrefixLM 是什么**？输入用双向，输出用单向，是 Decoder-only 和 Encoder-Decoder 的折中（如 GLM）。
