# 位置编码（高频考点）

> RoPE 必考！理解为什么 Transformer 需要位置编码、各种编码方案的差异。

---

## Q1: 为什么 Transformer 需要位置编码？

**答**：
**自注意力的置换不变性**：
- 如果把输入序列 $[x_1, x_2, x_3]$ 打乱成 $[x_3, x_1, x_2]$，Attention 输出会跟着打乱，但**每个位置的特征不变**。
- 也就是说，attention 把序列当成"集合"处理，看不到顺序信息。

而语言显然依赖顺序（"狗咬人" vs "人咬狗"）。所以需要显式注入位置信息。

**注入方式**：
1. 加到输入 embedding 上（Sinusoidal、Learned）
2. 作用于 Q、K（RoPE）
3. 加在注意力 logits 上（ALiBi、T5 bias）

---

## Q2: Sinusoidal 位置编码？

**答**：原始 Transformer 的方案。

$$PE_{(pos, 2i)} = \sin(pos / 10000^{2i/d})$$
$$PE_{(pos, 2i+1)} = \cos(pos / 10000^{2i/d})$$

- $pos$ 是位置索引，$i$ 是维度索引。
- 不同维度对应不同频率，从 $\omega_0 = 1$ 到 $\omega_{d/2-1} = 1/10000$。
- 偶数维 sin，奇数维 cos。

**为什么用 sin/cos**：
1. **唯一性**：不同位置编码不同。
2. **可外推**：固定函数，理论上能处理训练时未见过的长度（但实际外推性差）。
3. **相对位置可学**：$PE_{pos+k}$ 是 $PE_{pos}$ 的线性组合（旋转），模型可以学到相对位置关系。
4. **范围有界**：值域 $[-1, 1]$，加到 embedding 上不会爆炸。

**为什么用 10000 作 base**：经验值，覆盖足够大的位置范围。

---

## Q3: 绝对位置编码 vs 相对位置编码？

**答**：

| 类型 | 代表 | 特点 |
|------|------|------|
| 绝对 PE | Sinusoidal、Learned PE | 每个位置一个独立向量 |
| 相对 PE | T5 bias、ALiBi、RoPE | 编码 token 之间的相对距离 |

**绝对 PE 的问题**：
- 外推性差（位置 N+1 没见过）
- 加到 embedding 上后，attention 看到的是绝对位置，对"距离"不敏感

**相对 PE 的优势**：
- 自然支持外推
- 更符合语言的"相对依赖"直觉（"前面那个词"比"位置 17 的词"更通用）

**RoPE 是相对 PE 中的特殊形态**：用旋转实现，且不需要可学习参数。

---

## Q4: RoPE（旋转位置编码）的数学形式？

**答**：**必考！**

**核心思想**：把 Q、K 中每两个相邻维度看作复平面上的一个 2D 向量，按位置旋转。

**二维情形**：位置 $m$ 处的 Q 应用旋转：
$$R_m = \begin{pmatrix} \cos m\theta & -\sin m\theta \\ \sin m\theta & \cos m\theta \end{pmatrix}$$
$$q_m' = R_m q_m, \quad k_n' = R_n k_n$$

**关键性质**：
$$\langle q_m', k_n' \rangle = q^T R_m^T R_n k = q^T R_{n-m} k$$
- 旋转矩阵的内积**只依赖相对位置 $n-m$**！
- 这就是 RoPE 是相对位置编码的本质。

**复数视角**：把 2D 向量看作复数 $z = x + iy$，旋转就是乘以 $e^{im\theta}$。
$$\bar{q_m'} k_n' = \overline{e^{im\theta} q_m} \cdot e^{in\theta} k_n = e^{i(n-m)\theta} \bar{q_m} k_n$$
实部就是注意力分数，依然只与 $n-m$ 有关。

**高维实现**：把 $d$ 维向量分成 $d/2$ 对，每对用一个频率 $\theta_i = 10000^{-2i/d}$ 旋转。

**伪代码**：
```python
# x shape: [..., d]
def apply_rope(x, pos):
    # 把最后一维分两半
    x1, x2 = x[..., 0::2], x[..., 1::2]   # 偶 / 奇维度
    freq = 1.0 / (10000 ** (torch.arange(0, d, 2) / d))
    angle = pos.unsqueeze(-1) * freq      # [seq_len, d/2]
    cos, sin = angle.cos(), angle.sin()
    rotated = torch.stack([x1 * cos - x2 * sin,
                           x1 * sin + x2 * cos], dim=-1).flatten(-2)
    return rotated
```

## Q5: 为什么 RoPE 是相对位置编码？

**答**：上面已经证明：

$$\langle R_m q, R_n k \rangle = q^T R_{n-m} k$$

- 注意力分数只依赖 $n - m$，与绝对位置 $m, n$ 无关。
- 这正是相对位置编码的定义。
- 同时无需可学习参数（不像 T5 bias）。

---

## Q6: RoPE 的外推性？

**答**：
**优势**：
- 旋转操作连续可微，理论上可以外推到训练长度之外。
- 但实际上，**直接外推到 2 倍以上长度效果暴跌**：
  - 远距离的 token 旋转角度大，注意力分数变得难以预测
  - 训练时未见过的长距离关系，模型不知如何处理

**外推技术**：
1. **Position Interpolation (PI)**：把外推改成"内插"，把更长的序列位置缩到训练范围内。
   - 缺点：模糊了局部位置信息。
2. **NTK-Aware Scaling**：高频维度（短距离）不变，低频维度（长距离）按比例拉长。
   - 直觉：高频维度信息量大，不能动；低频本来就是平滑信号，缩放无害。
3. **YaRN**（Yet another RoPE extensioN）：NTK + 注意力温度调整的组合。
   - 当前最常用的扩展方案。
4. **LongRoPE**：在每个频率上独立搜索最优缩放因子。

## Q7: ALiBi（Attention with Linear Biases）？

**答**：
**思路**：不修改 Q/K，直接在注意力分数上加一个**线性偏置**惩罚远距离。

$$\text{score}_{ij} = q_i \cdot k_j - m \cdot |i - j|$$

- $m$ 是头特定的斜率（不同头不同 m，几何级数分布）
- 距离越远，惩罚越大（log-linear decay）

**优点**：
- 极简，无需修改 PE 模块
- 外推性极好（设计目标）

**缺点**：
- 限制了模型关注远距离的能力（实验上对长上下文质量略低于 RoPE）
- BLOOM、MPT 使用，但 LLaMA 后选择了 RoPE

---

## Q8: 长上下文外推技术对比？

**答**：

| 方案 | 思路 | 是否需训练 | 效果 |
|------|------|-----------|------|
| PI（Position Interpolation） | 位置内插（线性缩放） | 需短训 | 良 |
| NTK-Aware | 频率维度差异化缩放 | 可零样本 | 优 |
| **YaRN** | NTK + 温度修正 | 短训更优 | **当前 SOTA** |
| LongRoPE | 逐维度搜索缩放 | 需要搜索 | 极优 |
| ALiBi | 线性 bias 自带外推 | 无需 | 一般 |

**实际使用**：
- LLaMA 系列、Qwen 用 YaRN 或类似方案扩展到 128K。
- Mistral 用 Sliding Window Attention + RoPE。

---

## Q9: 位置编码加到哪一层？

**答**：
- **Sinusoidal / Learned**：加到 input embedding 上（只在最底层）。
- **RoPE / T5 bias / ALiBi**：在**每一层** attention 计算时应用。
- 这导致 RoPE 在每一层都注入位置信号，比绝对 PE 信号更强。

## 🎯 高频追问

1. **为什么 RoPE 的 base 是 10000？能不能改**？经验值，源自 Sinusoidal。可以改，扩展上下文时常把 base 改大（如 500000），让低频维度衰减得更慢，等效内插。
2. **RoPE 应用在 Q、K 还是 V**？只在 Q 和 K。V 不需要位置信息，因为它是"内容"，位置已通过 attention 权重表达。
3. **RoPE 的反向传播复杂吗**？不复杂，旋转矩阵的导数还是旋转矩阵的变种。实践中用 cos/sin 缓存。
4. **为什么 ALiBi 用线性而不是其他衰减**？指数衰减太陡，平方根太缓；线性是经验上的甜点。
5. **RoPE 的 head_dim 必须是偶数**？是的，要分对儿旋转。LLaMA head_dim=128 满足。
