## 🎯 手撕代码的通用套路

### 1. 先讲清楚再写

白板写代码前，**先口述思路 + 写公式**——面试官想看的是你的思维过程，不是默写。

### 2. 维度标注是命脉

每个 tensor 后面注释 shape，是手撕代码不出错的关键：

```python
Q = self.W_q(x)          # [B, L, D]
Q = Q.view(B, L, H, d).transpose(1, 2)   # [B, H, L, d]
```

### 3. 从最简版开始

先写"能跑的最朴素版"，再逐步加优化（batch、mask、多头）。

### 4. 主动写测试

写完跑一个 sanity check（shape 对不对、和 PyTorch 官方实现对不对），体现工程素养。

### 5. 数值稳定性意识

凡是涉及 `exp` / `log` / `softmax` 的，主动减最大值、加 `eps`——面试官最爱问这个。
