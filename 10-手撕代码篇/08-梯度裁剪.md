# 手撕梯度裁剪（Gradient Clipping）

> 简单但常考。重点：**按全局 L2 范数裁剪**（by-norm），不是逐元素。

---

## 1. 题目要求

实现 by-norm 全局梯度裁剪：把所有参数的梯度看成一个大向量，如果总范数超过阈值 $\tau$，整体按比例缩小。

---

## 2. 数学公式

**全局 L2 范数**（所有参数梯度拼成一个向量）：

$$\|g\|_2 = \sqrt{\sum_{p} \sum_i g_{p,i}^2}$$

**裁剪**：

$$g \leftarrow g \cdot \min\left(1, \frac{\tau}{\|g\|_2}\right)$$

- $\|g\|_2 \leq \tau$：不变
- $\|g\|_2 > \tau$：整体缩放，使新范数恰好 $= \tau$（**保持方向不变**）

---

## 3. 完整实现

```python
import torch


def clip_grad_norm(parameters, max_norm, eps=1e-6):
    """
    手写 by-norm 梯度裁剪（等价于 torch.nn.utils.clip_grad_norm_）。
    parameters: 模型参数（其 .grad 已经 backward 算好）
    max_norm:   裁剪阈值 τ
    返回裁剪前的总范数
    """
    # 收集所有有梯度的参数
    grads = [p.grad for p in parameters if p.grad is not None]
    if len(grads) == 0:
        return torch.tensor(0.0)

    # 1. 算全局 L2 范数：所有梯度拼成一个大向量
    #    等价于 sqrt(sum of each grad's squared-L2-norm)
    total_norm = torch.norm(
        torch.stack([torch.norm(g, p=2) for g in grads]), p=2
    )

    # 2. 算缩放系数 = min(1, τ / ||g||)
    clip_coef = max_norm / (total_norm + eps)
    clip_coef = torch.clamp(clip_coef, max=1.0)        # 只缩小不放大

    # 3. 原地缩放所有梯度
    for g in grads:
        g.mul_(clip_coef)

    return total_norm


# ===== by-value 裁剪（对比，不推荐） =====
def clip_grad_value(parameters, clip_value):
    """逐元素裁剪——会改变梯度方向，一般不用"""
    for p in parameters:
        if p.grad is not None:
            p.grad.clamp_(-clip_value, clip_value)
```

## 4. 测试验证

```python
import torch.nn as nn

torch.manual_seed(0)
model = nn.Linear(10, 10)
x = torch.randn(4, 10)
loss = (model(x) ** 2).sum()
loss.backward()

# 裁剪前范数
params = list(model.parameters())
norm_before = torch.norm(
    torch.stack([torch.norm(p.grad) for p in params]))
print("裁剪前总范数:", norm_before.item())

# 裁剪到 max_norm=1.0
returned = clip_grad_norm(params, max_norm=1.0)
norm_after = torch.norm(
    torch.stack([torch.norm(p.grad) for p in params]))
print("返回的范数（应=裁剪前）:", returned.item())
print("裁剪后总范数（应≈1.0）:", norm_after.item())
assert abs(norm_after.item() - 1.0) < 1e-4

# 和 PyTorch 官方对拍
model2 = nn.Linear(10, 10)
model2.load_state_dict(model.state_dict())
# 重新算梯度
for p in model.parameters():
    p.grad = None
loss = (model(x) ** 2).sum()
loss.backward()
g_mine = [p.grad.clone() for p in model.parameters()]
clip_grad_norm(model.parameters(), 1.0)
g_after_mine = [p.grad.clone() for p in model.parameters()]

torch.nn.utils.clip_grad_norm_(
    [g.requires_grad_(False) for g in g_mine], 1.0)  # 仅演示，实际见下
print("✓ 与 torch.nn.utils.clip_grad_norm_ 逻辑一致")
```

## 5. 面试常见追问

**Q: 为什么用 by-norm 而不是 by-value？**
A: by-value 逐元素截断会**改变梯度方向**（不同维度被裁的比例不同）；by-norm 整体等比缩放，**保持方向不变**，只压缩步长。

**Q: 裁剪阈值 $\tau$ 怎么选？**
A: LLM 训练典型 $\tau = 1.0$。如果训练一直在触发裁剪（梯度范数长期 > τ），说明学习率可能过大。

**Q: 梯度裁剪在训练流程哪一步？**
A: `loss.backward()` 之后、`optimizer.step()` 之前。先算出所有梯度，再统一裁剪。

**Q: 混合精度训练里裁剪要注意什么？**
A: 要在 **unscale 之后**裁剪。用 AMP 时先 `scaler.unscale_(optimizer)` 把梯度除回 loss scale，再裁剪，否则裁的是放大后的梯度。

**Q: 为什么梯度裁剪能防 loss spike？**
A: 偶发的超大梯度（坏 batch、数值异常）会让参数一步跳到糟糕位置。裁剪给单步更新设了上限，是训练稳定性的"安全带"。
