# 手撕 KL 散度

> RLHF / 蒸馏 / 变分推断都要用。重点是工程上常用的 **k1/k2/k3 估计器**。

---

## 1. 题目要求

实现 KL 散度：
- 精确版（有完整分布时）
- 采样估计版（只有样本 log-prob 时，RLHF 场景）

---

## 2. 数学公式

**定义**：

$$D_{KL}(P \| Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)} = \mathbb{E}_{x \sim P}\left[\log \frac{P(x)}{Q(x)}\right]$$

**RLHF 中的问题**：只有从 $\pi_\theta$ 采样的 token + 两个模型的 log-prob，要估 $D_{KL}(\pi_\theta \| \pi_{\text{ref}})$。

记 $r = \log \dfrac{\pi_{\text{ref}}(x)}{\pi_\theta(x)}$（注意方向），John Schulman 的三种估计器：

| 估计器 | 公式 | 特点 |
|---|---|---|
| **k1** | $-r$ | 无偏，方差大 |
| **k2** | $\frac{1}{2} r^2$ | 有偏，方差小 |
| **k3** | $(e^{r} - 1) - r$ | **无偏 + 低方差 + 恒非负**（GRPO 用） |

---

## 3. 完整实现

```python
import torch
import torch.nn.functional as F


def kl_exact(p_logits, q_logits):
    """精确 KL：有完整 logits 分布时。
    p_logits, q_logits: [..., vocab]
    返回 D_KL(P || Q)
    """
    p_logprob = F.log_softmax(p_logits, dim=-1)
    q_logprob = F.log_softmax(q_logits, dim=-1)
    p = p_logprob.exp()
    # sum_x p * (log p - log q)
    return (p * (p_logprob - q_logprob)).sum(dim=-1)


def kl_estimators(logp_theta, logp_ref):
    """采样估计：RLHF 场景，只有采样 token 的 log-prob。
    logp_theta: 当前策略 log π_θ(x),  [B, L]
    logp_ref:   参考策略 log π_ref(x), [B, L]
    估计 D_KL(π_θ || π_ref)，每个 token 一个估计值。
    """
    # r = log(π_ref / π_θ)
    r = logp_ref - logp_theta

    k1 = -r                          # 无偏，方差大
    k2 = 0.5 * r ** 2                # 有偏，方差小
    k3 = torch.exp(r) - 1 - r        # 无偏 + 低方差 + 恒 >= 0
    return k1, k2, k3
```

## 4. 测试验证

```python
torch.manual_seed(0)
V = 1000
p_logits = torch.randn(4, V)
q_logits = torch.randn(4, V)

# 精确 KL 应恒 >= 0
kl = kl_exact(p_logits, q_logits)
print("exact KL:", kl)
assert (kl >= -1e-5).all(), "KL 必须非负"

# P == Q 时 KL == 0
kl0 = kl_exact(p_logits, p_logits)
print("KL(P||P) ≈ 0:", kl0.abs().max().item())

# 采样估计：用大量样本验证 k3 的均值接近精确 KL
p = F.softmax(p_logits[0], dim=-1)
q = F.softmax(q_logits[0], dim=-1)
samples = torch.multinomial(p, 100000, replacement=True)
logp_theta = p[samples].log()        # 从 P 采样，π_θ = P
logp_ref = q[samples].log()          # π_ref = Q
k1, k2, k3 = kl_estimators(logp_theta, logp_ref)
print("精确 KL(P||Q):", kl_exact(p_logits[0], q_logits[0]).item())
print("k1 估计均值:  ", k1.mean().item())
print("k3 估计均值:  ", k3.mean().item())
print("→ k1, k3 均值都应接近精确值，但 k3 方差更小且恒非负")
print("k1 方差:", k1.var().item(), " k3 方差:", k3.var().item())
```

## 5. 面试常见追问

**Q: 为什么 RLHF 里不直接用精确 KL？**
A: 词表 5 万+，每步对全词表算 KL 太贵；而且生成是采样的，自然只有采样 token 的 log-prob。所以用采样估计。

**Q: k3 为什么比 k1 好？**
A: k1 无偏但方差大（单样本 $-r$ 可能为负）；k3 同样无偏，但恒非负、方差小，训练更稳。GRPO/PPO 实现常用 k3。

**Q: 为什么 k3 是 $e^r - 1 - r$？**
A: 它是 $\frac{q}{p} - 1 - \log\frac{q}{p}$ 的形式，期望恰好等于 $D_{KL}(p\|q)$，且因为 $e^r - 1 - r \geq 0$（对任意 r），所以恒非负。

**Q: KL 是对称的吗？**
A: 不对称，$D_{KL}(P\|Q) \neq D_{KL}(Q\|P)$。前向 KL（mode-covering）vs 反向 KL（mode-seeking）。

**Q: 交叉熵和 KL 什么关系？**
A: $H(P,Q) = H(P) + D_{KL}(P\|Q)$。训练时 $P$ 固定 → 最小化交叉熵 = 最小化 KL。
