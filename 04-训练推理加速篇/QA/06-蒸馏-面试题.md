## Q1: 写出经典 KD 的 loss 公式，解释每一项
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥🔥

Hinton 2015 经典 KD（Knowledge Distillation）：

$$\mathcal{L}_{\text{KD}} = (1 - \alpha) \cdot \mathcal{L}_{\text{CE}}(y, S(x)) + \alpha \cdot \tau^2 \cdot \mathcal{L}_{\text{KL}}\!\left(\frac{T(x)}{\tau}\ \Big\|\ \frac{S(x)}{\tau}\right)$$

**符号说明**：
- $T$ 教师（大模型），$S$ 学生（小模型）
- $T(x), S(x)$：教师/学生的 logits
- $y$：真实标签
- $\alpha$：两项 loss 平衡系数（典型 0.5-0.9）
- $\tau$：温度（典型 4-10）
- $\tau^2$：温度缩放会使梯度变小 $1/\tau^2$ 倍，乘 $\tau^2$ 补回去

**两项含义**：
- 第一项 CE：与真实标签的标准交叉熵（hard label）
- 第二项 KL：让学生匹配教师的软标签（soft label）

## Q2: 软标签比硬标签好在哪？这就是"暗知识"？
> 难度 ⭐⭐ ｜ 高频 🔥🔥🔥

**硬标签**：`[0, 1, 0, 0, 0]`——只告诉"正确答案"
**软标签**：`[0.05, 0.85, 0.07, 0.02, 0.01]`——同时告诉"第二可能、第三可能"

**信息量对比**：
- 硬标签：1 bit 级（哪个对）
- 软标签：$\log K$ bit 级（K 维概率分布）

**LLM 中**：词表 $K \approx 5\times 10^4$，软标签是 K 维分布，比硬 token 信息密集得多。

**"暗知识"（dark knowledge）**：教师对"错误答案的相对偏好"——比如把"cat"误判为"dog"概率比误判为"car"高，暗示猫狗相似。学生学到这种类别相似结构。

## Q3: 温度 $\tau$ 起什么作用？为什么蒸馏用大 $\tau$？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

带温度的 softmax：
$$P_i = \frac{\exp(z_i / \tau)}{\sum_j \exp(z_j / \tau)}$$

- $\tau = 1$：原 softmax
- $\tau > 1$：分布变平（暗知识被放大）
- $\tau \to \infty$：均匀分布
- $\tau \to 0$：尖到 argmax

**为什么用大 $\tau$**：正常 softmax 后非顶部 token 的概率几乎为 0（被 max 主导），温度放大后才能暴露"第二、第三可能"的相对信息。

**典型 $\tau = 4 \sim 10$**：太大分布过平→ 信号变弱；太小→ 暗知识被淹没。

**追问：为什么 loss 还要乘 $\tau^2$？** 软标签对 logits 的梯度规模 $\propto 1/\tau^2$，不乘的话学习率得跟 $\tau$ 联动调，乘 $\tau^2$ 后梯度量级稳定。

## Q4: 白盒蒸馏和黑盒蒸馏的区别？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

| | 白盒蒸馏 | 黑盒蒸馏 |
|---|---|---|
| 教师可见性 | logits / 隐藏层可访问 | 只能 API 调用，看输出文本 |
| 蒸馏目标 | logits、hidden state、attention map | 教师生成的文本 |
| 信号强度 | 强（软分布） | 弱（硬 token） |
| 典型应用 | DistilBERT、MiniLM、TinyBERT | GPT-4 生成数据 SFT 小模型 |
| 闭源教师 | 不能用 | **唯一选择** |

**白盒额外信号**：
- **Hidden state matching**：学生中间层匹配教师
- **Attention transfer**：学生 attention map 匹配教师

**黑盒严格说不算 KD**，但实际中（如蒸馏 GPT-4）应用最广。

## Q5: 反向 KL 蒸馏（MiniLLM）解决什么问题？
> 难度 ⭐⭐⭐⭐ ｜ 高频 🔥

**传统 KD 用前向 KL** $D_{KL}(\pi_T \| \pi_S)$：mode-covering——学生要覆盖教师所有概率不为 0 的模式，但教师在小概率"垃圾"模式上的非零概率会让学生也学到。

**MiniLLM 用反向 KL** $D_{KL}(\pi_S \| \pi_T)$：mode-seeking——学生聚焦教师的**高概率模式**，避免学到教师的低质量输出。

**符号说明**：$\pi_S$ 学生策略，$\pi_T$ 教师策略。

**直觉**：反向 KL 让学生"保守"——不敢去教师认为不可能的区域，更适合生成式任务。

**追问：为什么生成式特别需要 mode-seeking？** 生成空间巨大，前向 KL 让学生分散学习每个分支，结果都学得稀；反向 KL 让学生集中学好"主要分支"，质量更高。

## Q6: DeepSeek-R1-Distill 的关键发现是什么？
> 难度 ⭐⭐⭐ ｜ 高频 🔥🔥

**流程**：
1. 用 R1（671B 推理模型）生成大量带长 CoT 的数据
2. 用这些数据 SFT 小模型（Qwen-7B、LLaMA-8B 等）
3. 结果：蒸馏后的 7B 数学推理能力**超过未蒸馏的 32B**

**关键发现**：在**小模型**上，**蒸馏 > 直接 RL**。

**为什么**：
- 小模型探索能力弱，直接 RL 难收敛（探索失败、奖励稀疏）
- 蒸馏让学生直接学到 R1 已验证过的好推理路径，绕开探索难题

**启示**：**推理能力可以从大模型 transfer 到小模型**，且效率远高于让小模型自己学。

## Q7: "SFT-on-distilled-data"和经典 KD 是同一回事吗？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

**严格说不是**：
- 经典 KD 用教师的**软标签**（概率分布）作为目标
- 蒸馏数据 SFT 用教师生成的**硬 token**（采样后的文本），学生在数据上做标准 next-token prediction

**差异**：
| | 经典 KD | 蒸馏数据 SFT |
|---|---|---|
| 信号 | 软分布（K 维） | 硬 token（1 个） |
| 信息密度 | 高 | 低 |
| 实现 | 需教师 logits | 只需教师 API |
| 闭源教师 | 不能用 | **可以** |

但实际中两者都被泛称为"蒸馏"。GPT-4 生成数据训练小模型基本属于后者。

## Q8: 蒸馏的典型工作有哪些？
> 难度 ⭐ ｜ 高频 🔥

| 模型 | 教师 | 学生 | 方法 |
|---|---|---|---|
| DistilBERT | BERT | 半层 BERT | 软标签 + 隐藏匹配 |
| MiniLM | BERT/RoBERTa | 6 层 | 注意力 + value 匹配 |
| TinyBERT | BERT | 4 层 | 多层级蒸馏 |
| Zephyr | Mixtral | Mistral-7B | DPO + SFT 数据蒸馏 |
| **DeepSeek-R1-Distill** | R1（671B） | Qwen/LLaMA | R1 生成数据 SFT |
| Gemma 2 | Gemini | 自家小模型 | 多技术结合 |

**LLM 时代趋势**：从结构对齐型（DistilBERT）转向数据生成型（R1-Distill），因为 LLM 闭源居多。

## Q9: 蒸馏的常见坑有哪些？
> 难度 ⭐⭐ ｜ 高频 🔥

1. **学生容量不足**：教师太强，学生学不来——典型阈值 5-10× 参数差还能保留 95%+ 性能，20× 后明显掉
2. **数据偏差**：教师生成数据带特定风格，学生学得"画风过重"
3. **教师错误传递**：教师错的也会被学，需要质量过滤
4. **温度选错**：太低信号少；太高分布太平
5. **目标不对齐**：蒸馏多任务时各任务难度不同，单一 $\alpha, \tau$ 不够

## Q10: 蒸馏和量化怎么组合？
> 难度 ⭐⭐ ｜ 高频 🔥🔥

**两者正交**：
- **蒸馏**：压缩参数**数量**（70B → 7B）
- **量化**：压缩参数**精度**（FP16 → INT4）

**典型流程**：
1. 训练大教师模型（如 70B）
2. 蒸馏到小学生（如 7B）
3. 量化学生（如 INT4）
4. 部署：70B FP16 (140GB) → 7B INT4 (3.5GB)，**40× 压缩**

**追问：能反过来吗（先量化再蒸馏）？** 一般不——量化后的模型作为学生易丢失精度信号；让 FP16 学生先学到能力，再量化更稳。
