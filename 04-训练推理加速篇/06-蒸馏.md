# 知识蒸馏（Distillation）

> 让小模型继承大模型能力的关键技术。

---

## Q1: 知识蒸馏的核心思想？

**答**：
**Hinton (2015)** 经典 KD：
- 教师模型 $T$（大）输出"软标签"（概率分布）
- 学生模型 $S$（小）学习匹配教师的软标签
- 软标签包含"暗知识"（dark knowledge）：错误类别的相对概率反映了类别相似性

**损失函数**：
$$\mathcal{L} = (1-\alpha) \mathcal{L}_{CE}(y, S(x)) + \alpha T^2 \mathcal{L}_{KL}(T(x)/T, S(x)/T)$$

- 第一项：与真实标签的 CE 损失
- 第二项：与教师软标签的 KL 散度
- $T$（温度）：通常 4-10，让分布更平滑暴露暗知识

**为什么乘 $T^2$**：温度缩放使梯度变小（$1/T^2$），乘回保证梯度量级稳定。

---

## Q2: 软标签为什么比硬标签好？

**答**：
**硬标签**：[0, 1, 0, 0, 0]
- 只告诉模型"正确答案"
- 信息量低

**软标签**（教师输出）：[0.05, 0.85, 0.07, 0.02, 0.01]
- 不仅给出正确答案，还指出"第二可能"
- 隐含类别相似性信息（哪些类似哪些不同）
- 信息密度高得多

**LLM 中应用**：
- 学生学到教师对每个 token 的概率分布
- 比只学硬 token 信息丰富 K 倍（K = vocab size）

## Q3: 白盒 vs 黑盒蒸馏？

**答**：

| 类型 | 教师可见性 | 蒸馏目标 | 适用 |
|------|----------|---------|------|
| **白盒蒸馏** | 教师 logits/中间层可访问 | logits、隐藏态、attention map | 开源教师 |
| **黑盒蒸馏** | 只能 API 调用 | 教师生成的文本 | GPT-4 等闭源 |

**白盒蒸馏的额外信号**：
- **Hidden state matching**：让学生中间层接近教师
- **Attention transfer**：让学生 attention map 接近教师
- 信号更丰富，效果更好

**黑盒蒸馏典型**：
- 用 GPT-4 生成大量优质数据
- 用这些数据 SFT 小模型
- 严格说不是经典 KD，但实际应用广泛

## Q4: LLM 蒸馏的典型工作？

**答**：

| 模型 | 教师 | 学生 | 方法 |
|------|------|------|------|
| DistilBERT | BERT | 半层 BERT | 软标签 + 隐藏匹配 |
| MiniLM | BERT/RoBERTa | 6 层 | 注意力 + value 匹配 |
| TinyBERT | BERT | 4 层 | 多层级蒸馏 |
| Zephyr | Mixtral | Mistral-7B | DPO + SFT 数据蒸馏 |
| **DeepSeek-R1-Distill** | R1（推理大模型） | Qwen/LLaMA | 用 R1 生成数据 SFT |
| **Gemma 2** | Gemini | 自己 | 多种 KD 技术结合 |

**DeepSeek-R1-Distill 启示**：
- 推理大模型生成的长 CoT 数据可以蒸馏到小模型
- 1.5B 模型经蒸馏后数学推理超越未蒸馏的 32B
- 证明"推理能力可蒸馏"

## Q5: KD 的具体损失形式？

**答**：
**Logit 蒸馏**（最常见）：
$$\mathcal{L}_{KD} = T^2 \cdot D_{KL}(\sigma(z_T / T) \| \sigma(z_S / T))$$

**前向 KL vs 反向 KL**：
- **前向 KL** $D_{KL}(P_T \| P_S)$：mode-covering，学生覆盖教师所有 mode
- **反向 KL** $D_{KL}(P_S \| P_T)$：mode-seeking，学生聚焦教师高概率模式（在生成式 LLM 中常用）

**MiniLLM**（白盒生成式 KD）：
- 用反向 KL（避免学生分配概率到教师认为不可能的输出）
- 配合 policy gradient 训练

## Q6: SFT-on-Distilled-Data 是不是 KD？

**答**：
**严格意义上不是**，但实际中常被称为"蒸馏"：
- 教师（GPT-4）生成 (prompt, response) 数据
- 学生在数据上做 SFT（用硬 token loss）
- 没有用教师的软标签

**与经典 KD 的差异**：
- 信号弱（硬标签 vs 软分布）
- 但实现极简单（只需教师 API）
- 闭源教师场景几乎只能这样做

**优化版本**：
- 多次采样选最优（rejection sampling）
- 添加合理性检查
- 用 multiple teacher 集成

## Q7: 蒸馏的常见坑？

**答**：
1. **学生容量不足**：教师太强，学生学不来。需要找合适尺寸学生。
2. **数据偏差**：教师生成数据有特定风格，学生过拟合此风格。
3. **教师错误**：教师的错误会被学生学到。需要质量过滤。
4. **温度选择**：太低（接近硬标签，信息少）；太高（分布太平，信号弱）。常用 T=4-10。
5. **多教师**：用多个教师集成可降低偏差，但实现复杂。

---

## Q8: 蒸馏与量化的关系？

**答**：
- **蒸馏**：压缩参数数量（大 → 小）
- **量化**：压缩参数精度（FP16 → INT4）
- **可组合**：先蒸馏后量化，节省效果叠加

**典型流程**：
1. 训练大教师模型
2. 蒸馏到小学生（如 70B → 7B）
3. 量化学生（INT4）
4. 部署

---

## Q9: 推理模型的蒸馏（R1-Distill）有什么特殊？

**答**：
**DeepSeek-R1 论文实验**：
- 用 R1（推理大模型，671B）生成大量带长 CoT 的样本
- 用这些样本 SFT 小模型（Qwen-7B、Llama-8B 等）
- 蒸馏后的小模型推理能力大幅提升

**关键发现**：
- **蒸馏 > 直接 RL（在小模型上）**
- 7B 模型通过 R1 数据蒸馏 > 7B 模型直接 RL
- 原因：小模型探索能力弱，直接 RL 难收敛；蒸馏直接学到 R1 已验证的好路径

**意义**：
- 推理能力可以从大模型 transfer 到小模型
- 部署小模型即可获得近似大模型的推理能力

---

## Q10: 蒸馏在 LLM 时代的实际地位？

**答**：
**大模型时代蒸馏的几种形态**：
1. **数据蒸馏**：用强模型生成数据训弱模型（最常用）
2. **白盒蒸馏**：开源模型间，效果好但限制多
3. **能力蒸馏**：把特定能力（如长 CoT、工具调用）蒸馏到小模型
4. **多模态蒸馏**：把视觉/音频模态能力转给纯文本模型（或反之）

**典型成功案例**：
- Vicuna：从 ShareGPT（GPT-3.5 生成）蒸馏
- Zephyr：从 Mixtral 蒸馏（白盒 + DPO）
- 各家小模型大量用 GPT-4 数据训练

## 🎯 高频追问

1. **温度 T 越大越好吗**？不是。太大分布过平，信号变弱。T=4-10 是甜点。
2. **能蒸馏多模态吗**？可以，如 CLIP 蒸馏出小 CLIP；视觉教师蒸馏给小视觉模型。
3. **学生需要和教师同结构吗**？不需要。但同结构（如 LLaMA-70B → LLaMA-7B）效果更好（hidden state matching 可用）。
4. **蒸馏能压缩多少**？通常 5-10× 参数压缩可保留 95%+ 性能；20× 后开始明显下降。
5. **黑盒蒸馏的合法性**？取决于教师 API 的服务条款。OpenAI 等明确禁止用其输出训练竞品模型。
