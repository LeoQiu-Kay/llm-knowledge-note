# 知识蒸馏（Distillation）

> 让小模型继承大模型能力的关键技术。

---

## 1. 核心思想

**Hinton (2015) 经典 KD**：
- 教师模型 $T$（大）输出"软标签"（概率分布）
- 学生模型 $S$（小）学习匹配教师的软标签
- 软标签包含"暗知识"（dark knowledge）

**损失函数**：

$$\mathcal{L}_{\text{KD}} = (1 - \alpha) \cdot \mathcal{L}_{\text{CE}}(y, S(x)) + \alpha \cdot T^2 \cdot \mathcal{L}_{\text{KL}}\left(\frac{T(x)}{\tau}, \frac{S(x)}{\tau}\right)$$

**符号说明**：
- $T$（大写 T，教师）：教师模型；同时 $T(x)$ 是教师对输入 $x$ 的 logits 输出
- $S$（学生）：学生模型；$S(x)$ 是学生的 logits
- $y$：真实标签
- $\mathcal{L}_{\text{CE}}$：交叉熵损失
- $\mathcal{L}_{\text{KL}}$：KL 散度
- $\alpha$（alpha）：两项 loss 的平衡系数（典型 0.5-0.9）
- $\tau$（tau，温度）：通常 4-10，让分布更平滑暴露暗知识
- $T^2$：乘 $\tau^2$ 保证梯度量级稳定（温度缩放使梯度变小 $1/\tau^2$，乘回补偿）

**两项含义**：
- 第一项：与真实标签的 CE 损失（hard label）
- 第二项：与教师软标签的 KL（soft label）

---

## 2. 软标签为什么比硬标签好？

**硬标签**：[0, 1, 0, 0, 0]
- 只告诉模型"正确答案"
- 信息量低

**软标签**（教师输出）：[0.05, 0.85, 0.07, 0.02, 0.01]
- 不仅给出正确答案，还指出"第二可能"
- 隐含类别相似性
- 信息密度高得多

**LLM 中**：学生学到教师对每个 token 的**概率分布**（词表大小 $K$ 维），比只学硬 token 信息丰富 $K$ 倍。

---

## 3. 温度 $\tau$ 的作用

带温度的 softmax：

$$P_i = \frac{\exp(z_i / \tau)}{\sum_j \exp(z_j / \tau)}$$

**符号说明**：
- $z_i$：第 $i$ 个 token 的 logit
- $\tau$：温度

**效果**：
- $\tau = 1$：原始 softmax
- $\tau > 1$：分布变平（暗知识被放大）
- $\tau \to \infty$：均匀分布

```text
为什么用大 τ 蒸馏？
正常 softmax 后非顶部 token 的概率几乎为 0，
温度放大后可以暴露 "第二、第三可能" 的相对信息。
```

典型 $\tau = 4 \sim 10$。

## 4. 白盒 vs 黑盒蒸馏

| | 教师可见性 | 蒸馏目标 |
|---|---|---|
| **白盒蒸馏** | logits / 隐藏层可访问 | logits、隐藏态、attention map |
| **黑盒蒸馏** | 只能 API 调用 | 教师生成的文本 |

**白盒额外信号**：
- **Hidden state matching**：学生中间层接近教师
- **Attention transfer**：学生 attention map 接近教师

**黑盒**：
- 用 GPT-4 等生成大量优质数据
- 用这些数据 SFT 小模型
- 严格说不是经典 KD，但实际广泛应用

## 5. LLM 蒸馏的典型工作

| 模型 | 教师 | 学生 | 方法 |
|---|---|---|---|
| DistilBERT | BERT | 半层 BERT | 软标签 + 隐藏匹配 |
| MiniLM | BERT/RoBERTa | 6 层 | 注意力 + value 匹配 |
| TinyBERT | BERT | 4 层 | 多层级蒸馏 |
| Zephyr | Mixtral | Mistral-7B | DPO + SFT 数据蒸馏 |
| **DeepSeek-R1-Distill** | R1（671B 推理） | Qwen/LLaMA | 用 R1 生成数据 SFT |
| Gemma 2 | Gemini | 自己 | 多种 KD 技术结合 |

## 6. 反向 KL 蒸馏（生成式）

**问题**：传统 KD 用前向 KL，可能让学生"覆盖教师所有模式"——但教师可能给些低质量模式概率，学生学了反而差。

**MiniLLM**（白盒生成式 KD）：用**反向 KL**：

$$\mathcal{L} = D_{KL}(\pi_S \| \pi_T)$$

**符号**：
- $\pi_S$：学生策略
- $\pi_T$：教师策略

mode-seeking：学生聚焦教师高概率模式，避免散到教师认为不可能的输出。

---

## 7. DeepSeek-R1-Distill 的启示

DeepSeek-R1 论文实验：
- 用 R1（671B 推理模型）生成大量带长 CoT 的数据
- 用这些数据 SFT 小模型（Qwen-7B、LLaMA-8B 等）
- 蒸馏后的 7B 数学推理能力 **超过未蒸馏的 32B**

**关键发现**：
- **蒸馏 > 直接 RL（在小模型上）**
- 7B 模型通过 R1 数据 SFT > 7B 模型直接 RL
- 原因：小模型探索能力弱，直接 RL 难收敛；蒸馏直接学到 R1 已验证的好路径

```text
推理能力可以从大模型 transfer 到小模型。
```

---

## 8. SFT-on-Distilled-Data 是不是 KD？

**严格意义上不是**，但实际中常被称为"蒸馏"：
- 教师（GPT-4）生成 (prompt, response) 数据
- 学生在数据上 SFT（用硬 token loss）
- 没有用教师的软标签

**与经典 KD 的差异**：
- 信号弱（硬标签 vs 软分布）
- 但实现极简单（只需教师 API）
- 闭源教师场景几乎只能这样做

---

## 9. 蒸馏的常见坑

1. **学生容量不足**：教师太强，学生学不来
2. **数据偏差**：教师生成数据有特定风格
3. **教师错误**：教师错误会被学生学到（质量过滤）
4. **温度选择**：太低信息少；太高分布太平
5. **多教师**：可降低偏差，但实现复杂

---

## 10. 蒸馏 + 量化组合

- **蒸馏**：压缩参数数量（大 → 小）
- **量化**：压缩参数精度（FP16 → INT4）
- **可组合**：节省效果叠加

**典型流程**：
1. 训练大教师模型
2. 蒸馏到小学生（如 70B → 7B）
3. 量化学生（INT4）
4. 部署

---

## 11. 最简记忆

```text
KD 损失 = α·KL(教师, 学生) + (1-α)·CE(真实标签, 学生)
温度 τ：放大软标签的"暗知识"（典型 4-10）

白盒：可访问 logits / 中间层
黑盒：只用文本输出（GPT-4 生成数据 SFT 小模型）

DeepSeek-R1-Distill 启示：
  小模型直接 RL 难，用大模型 R1 生成数据 SFT 反而更好。

蒸馏 + 量化叠加 → 大幅压缩模型部署成本。
```

## 🎯 高频追问

1. **温度 $\tau$ 越大越好吗**？不是。太大分布过平，信号变弱。$\tau = 4 \sim 10$ 是甜点。

2. **能蒸馏多模态吗**？可以，如 CLIP 蒸馏出小 CLIP。

3. **学生必须和教师同结构吗**？不必，但同结构（LLaMA-70B → LLaMA-7B）更易做 hidden state matching。

4. **蒸馏能压缩多少**？通常 5-10× 参数可保留 95%+ 性能；20× 后明显下降。

5. **黑盒蒸馏的合法性**？看教师 API 的服务条款。OpenAI 等明确禁止用其输出训练竞品模型。
