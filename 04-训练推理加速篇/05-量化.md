# 量化（Quantization）

> 让大模型跑在小硬件上的关键技术。GPTQ/AWQ 必知。

---

## 1. 为什么需要量化？

**问题**：
- LLaMA-2-70B FP16 需要 140 GB → 单 80GB H100 装不下
- 推理是 memory-bound，更小数据类型 = 更快加载
- 边缘设备（手机、笔记本）只有 8-32 GB

**量化的好处**：
- **显存节省**：INT4 是 FP16 的 1/4
- **带宽节省**：HBM 读取等比提升
- **推理加速**：通常 1.5-3×
- **代价**：精度损失（要尽量小）

---

## 2. PTQ vs QAT

| | PTQ（训练后量化） | QAT（量化感知训练） |
|---|---|---|
| 时机 | 训练完后 | 训练过程中 |
| 数据 | 少量校准集（几百样本） | 完整训练集 |
| 训练成本 | 低（几小时） | 高（重新训练） |
| 精度 | 中等 | 高 |
| LLM 主流 | **是**（GPTQ、AWQ） | 少（成本高） |

```text
LLM 几乎全用 PTQ：重训成本高，PTQ 用聪明算法已能保持效果。
```

## 3. 量化的数学基础

### 3.1 对称量化

$$x_{\text{quant}} = \text{round}\left(\frac{x}{s}\right), \quad x_{\text{dequant}} = x_{\text{quant}} \cdot s$$

**符号说明**：
- $x$：原始浮点值
- $s$：scale（缩放因子，标量）
- $x_{\text{quant}}$：量化后的整数（如 INT8 取值 $[-128, 127]$）
- $x_{\text{dequant}}$：反量化回浮点（有小损失）
- $\text{round}$：取整

scale 一般取：

$$s = \frac{\max(|x|)}{2^{b-1} - 1}$$

**符号**：$b$ 是位宽（INT8 时 $b = 8$）。

### 3.2 非对称量化

增加 zero-point $z$ 处理分布偏移：

$$x_{\text{quant}} = \text{round}\left(\frac{x}{s}\right) + z$$

$$x_{\text{dequant}} = (x_{\text{quant}} - z) \cdot s$$

**LLM 中**：权重多对称（接近正态分布），激活/KV Cache 多非对称（有偏移）。

## 4. GPTQ：基于 Hessian 的逐层量化

**核心思想**：逐列量化权重，用未量化列**补偿**当前列的量化误差。

**算法概览**：
1. 按重要性排序权重列
2. 对每个权重列：
   - 量化当前列
   - 用剩余未量化列**补偿**量化误差
3. 利用 Hessian 矩阵的逆来计算最优补偿

**关键公式**：

$$\Delta W_{\text{rest}} = -\frac{w_q - \hat{w}_q}{[H^{-1}]_{q,q}} \cdot [H^{-1}]_{q, \text{rest}}$$

**符号说明**：
- $w_q$：当前列量化前
- $\hat{w}_q$：当前列量化后
- $H^{-1}$：Hessian 矩阵的逆
- $[H^{-1}]_{q,q}$：对角元
- $[H^{-1}]_{q, \text{rest}}$：当前列与其他列的交叉项

**优势**：
- 效果好（INT4 几乎无损）
- 速度快（4-bit 70B 模型几小时完成）
- 开源实现成熟（AutoGPTQ）

## 5. AWQ：激活值感知的权重量化

**AWQ**（Activation-aware Weight Quantization）。

**关键观察**：**激活值大的 weight channel 更重要**。

- 实际只有约 1% 的 weight 是"显著"的（对应 outlier 激活）
- 保留这 1% 用 FP16，其余 INT4 → 效果显著提升

**算法**：
1. 用少量校准数据统计激活幅度
2. 对 weight 做 per-channel scaling：

$$W' = W \cdot \text{diag}(s)$$

**符号说明**：
- $W$：原始权重
- $s$：缩放向量（激活大的 channel 对应 $s$ 大）
- $\text{diag}(s)$：把向量变成对角矩阵
- $W'$：缩放后的权重（更易量化）

3. 量化 $W'$ 得 $W_q$
4. 推理时：$y = (W_q x) / s$（除回去）

**优势**：
- 比 GPTQ 略好或持平
- 不需要 backward
- 硬件友好

## 6. SmoothQuant：让 W8A8 可行

**目的**：W8A8（权重和激活都 INT8）。

**问题**：激活有 outlier，直接 INT8 量化失真严重。

**SmoothQuant 解法**：把 outlier 从激活"转移"到权重：

$$Y = X \cdot W = \left(X \cdot \text{diag}(s)^{-1}\right) \cdot \left(\text{diag}(s) \cdot W\right) = X' \cdot W'$$

**符号说明**：
- $X$：激活（含 outlier）
- $W$：权重
- $s$：转移因子（标量向量）
- $X' = X / s$：激活变平滑
- $W' = s \cdot W$：权重承担难度
- 数学上等价，但 $X', W'$ 都更易量化

**$s$ 的选择**：让 $X'$ 和 $W'$ 都易量化的平衡点：

$$s_j = \frac{\max(|X_j|)^\alpha}{\max(|W_j|)^{1-\alpha}}, \quad \alpha = 0.5$$

## 7. NF4：QLoRA 的数据类型

**NF4**（Normal Float 4-bit）：专为正态分布权重设计。

**原理**：
- 量化值**不均匀**分布，而是按标准正态分布的分位数选取
- 16 个量化点中间密、两端疏 → 匹配权重的正态分布
- 量化误差最小化

**对比**：
- INT4：均匀分布 16 个点
- FP4：1 符号 + 2 指数 + 1 尾数
- **NF4**：16 个非均匀点（按正态分位数）

## 8. W4A16 / W8A8 / W4A8 是什么意思？

**符号约定**：**W = Weight 精度，A = Activation 精度**。

| 类型 | 含义 | 节省 | 适用 |
|---|---|---|---|
| W16A16 | FP16 权重 + FP16 激活 | 基线 | 标准 |
| **W4A16** | INT4 权重 + FP16 激活 | 主要省显存 | **GPTQ/AWQ 主流** |
| W8A8 | INT8 权重 + INT8 激活 | 2× 显存 + 算力 | TRT-LLM |
| W4A8 | INT4 权重 + INT8 激活 | 更激进 | 高性能场景 |
| FP8 | 8-bit 浮点 | 介于 INT8 和 BF16 | H100 友好 |

```text
最常用：W4A16（GPTQ/AWQ），平衡精度与速度。
```

## 9. 量化敏感层

以下层对量化更敏感，应保留高精度：

1. **LayerNorm / RMSNorm 的输入**：归一化放大量化误差
2. **第一层**：直接接收 embedding，扰动放大到全网
3. **最后一层 LM Head**：决定输出分布
4. **Attention 中的 softmax 输入**：尖锐分布对误差敏感

**应对**：
- 敏感层用 FP16 / FP8
- 其余 INT4
- 称为**混合精度量化**

---

## 10. 量化对效果的影响

典型 LLM 经验数据：

| 精度 | MMLU 损失 | 显存节省 |
|---|---|---|
| FP16 | 0%（基线） | 1× |
| INT8 (W8A8) | < 0.5% | 2× |
| **INT4 (W4A16, GPTQ/AWQ)** | **1-2%** | **4×** |
| INT3 | 3-5% | 5.3× |
| INT2 | > 10% | 8× |

```text
INT4 是甜点：效果损失可接受，节省显著。
INT3 / INT2 损失大，仅极端场景。
```

## 12. 最简记忆

```text
量化的根本目的：节省显存 + 加速推理（memory-bound）

PTQ vs QAT → LLM 全用 PTQ

主流算法：
  GPTQ    基于 Hessian 的逐列补偿  → 经典
  AWQ     按激活重要性缩放 weight  → 更简单、效果接近
  SmoothQuant  把 outlier 转移给权重 → 实现 W8A8
  NF4     专为正态分布设计的 4-bit → QLoRA 用

W4A16 是甜点（4× 节省，1-2% MMLU 损失）

敏感层（LN 输入、首层、末层、softmax 输入）保留高精度。
```

## 🎯 高频追问

1. **GPTQ 和 AWQ 哪个好**？效果接近，AWQ 略简单（无需 backward）。实践 AWQ 略主流。

2. **为什么不用 INT2**？精度损失大，硬件支持差。

3. **量化要校准吗**？PTQ 需要校准数据（几百样本），常用 WikiText 等通用数据。

4. **量化模型能微调吗**？QLoRA 的核心：base 量化 + LoRA 微调。

5. **FP8 vs INT8 谁好**？FP8 有指数位，动态范围大，对 outlier 友好；INT8 精度均匀。H100 上 FP8 通常更好。
