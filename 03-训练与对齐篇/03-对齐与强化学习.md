# 对齐与强化学习（RLHF / DPO / GRPO）

> 让模型"听话"的核心。PPO → DPO → GRPO 演进必背。

---

## 1. RLHF 三阶段流程

**Step 1：SFT** — 用高质量人工示范微调 base 模型。

**Step 2：RM（Reward Model）** — 训练标量奖励模型。

**Step 3：RL（PPO / GRPO 等）** — 用 RM 提供奖励，强化学习更新策略。

目标：

$$\max_\theta \mathbb{E}_{x, y \sim \pi_\theta}[r(x, y) - \beta \, D_{KL}(\pi_\theta(\cdot \mid x) \, \| \, \pi_{\text{ref}}(\cdot \mid x))]$$

**符号说明**：
- $\theta$：被训练的 policy 参数
- $\pi_\theta$：当前策略（被训的 LLM）
- $\pi_{\text{ref}}$：参考策略（冻结的 SFT 模型）
- $x$：prompt
- $y$：模型回答
- $r(x, y)$：奖励（从 RM 来）
- $\beta$（beta）：KL 惩罚系数（典型 0.01-0.1）
- $D_{KL}(\cdot \| \cdot)$：KL 散度（约束不要偏离 SFT）

---

## 2. Reward Model 训练

**数据格式**：$(x, y_w, y_l)$ 三元组。

**符号**：
- $x$：prompt
- $y_w$：被标为"更好"的答案（**w**inner）
- $y_l$：被标为"更差"的答案（**l**oser）

**损失**（Bradley-Terry 模型）：

$$\mathcal{L}_{RM} = -\mathbb{E}_{(x, y_w, y_l)} \left[\log \sigma(r_\phi(x, y_w) - r_\phi(x, y_l))\right]$$

**符号说明**：
- $r_\phi$：RM 模型（参数 $\phi$），输出标量奖励
- $\sigma$：sigmoid 函数 $\sigma(z) = \frac{1}{1 + e^{-z}}$
- $\mathbb{E}$：在偏好数据上求期望

**直觉**：让 $r(y_w) > r(y_l)$ 的差距尽可能大（log-sigmoid 把差距推开）。

**模型结构**：通常用 SFT 模型初始化，把 lm_head 替换为单标量输出 head。

---

## 3. PPO 在 RLHF 中的细节

**PPO 需要 4 个模型**：
1. **Actor / Policy** $\pi_\theta$：被优化的模型
2. **Critic / Value** $V_\phi$：估计状态价值
3. **Reward Model** $r$：提供奖励（冻结）
4. **Reference** $\pi_{\text{ref}}$：SFT 副本（冻结，用于 KL 约束）

### 3.1 实际奖励（加 KL 惩罚）

$$r_{\text{total}}(x, y) = r(x, y) - \beta \log \frac{\pi_\theta(y \mid x)}{\pi_{\text{ref}}(y \mid x)}$$

每个 token 都会算 KL 项作为"per-step reward"。

### 3.2 PPO clip 目标

$$\mathcal{L}^{\text{CLIP}}(\theta) = \mathbb{E}_t \left[\min(\rho_t A_t, \, \text{clip}(\rho_t, 1-\epsilon, 1+\epsilon) A_t)\right]$$

**符号说明**：
- $\rho_t = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\text{old}}(a_t \mid s_t)}$：重要性采样比（新旧策略概率比）
- $A_t$：在第 $t$ 步的 advantage（用 GAE 估计）
- $\epsilon$（epsilon）：clip 阈值（典型 0.2）
- $a_t$：第 $t$ 步的 action（生成的 token）
- $s_t$：第 $t$ 步的 state（历史 token）
- $\pi_{\text{old}}$：上一轮的策略

**直觉**：clip 防止 policy 更新过激（单步更新幅度被限制在 $\pm \epsilon$ 内）。

### 3.3 GAE（Generalized Advantage Estimation）

$$A_t = \sum_{l=0}^{T-t} (\gamma \lambda)^l \delta_{t+l}$$

$$\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$$

**符号说明**：
- $\delta_t$：TD 误差（时序差分）
- $\gamma$（gamma）：折扣因子（典型 0.99）
- $\lambda$（lambda）：GAE 平滑系数（典型 0.95）
- $V$：critic 估计的价值
- $T$：rollout 总长度

---

## 4. 为什么需要 KL 惩罚？

**目的**：防止 policy 偏离 SFT 模型太多。

**问题**：
- 不约束 → policy 找 RM 漏洞（**reward hacking**）
- 或偏离自然语言分布（mode collapse）
- 失去 SFT 学到的能力

**实现**：reward 中减去 KL：

$$r' = r - \beta \log \frac{\pi_\theta}{\pi_{\text{ref}}}$$

$\beta$ 太大约束太强、太小失控。可以**自适应调整 $\beta$**（看 KL 实际值动态变化）。

---

## 5. DPO：跳过 RM 的革命

**DPO**（Direct Preference Optimization, NeurIPS 2023）：直接用偏好数据训 policy。

### 5.1 推导路线

从 RLHF 最优解（KL 约束下）有解析形式：

$$\pi^*(y \mid x) = \frac{1}{Z(x)} \pi_{\text{ref}}(y \mid x) \exp\left(\frac{r(x, y)}{\beta}\right)$$

**符号**：$Z(x)$ 是归一化常数。

反解 reward：

$$r(x, y) = \beta \log \frac{\pi^*(y \mid x)}{\pi_{\text{ref}}(y \mid x)} + \beta \log Z(x)$$

代入 Bradley-Terry 偏好损失（$\log Z(x)$ 同 prompt 下被消掉）→ DPO 目标：

$$\mathcal{L}_{\text{DPO}} = -\mathbb{E}\left[\log \sigma\left(\beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)}\right)\right]$$

**符号说明**：
- $\pi_\theta$：要训的 policy
- $\pi_{\text{ref}}$：参考（冻结）
- $y_w, y_l$：偏好对
- $\beta$：温度（典型 0.1-0.5）

**关键性质**：
- 不需要 RM、不需要 RL
- 监督学习形式，训练简单稳定
- 只需 2 个模型（policy + ref）

### 5.2 DPO vs PPO

| 维度 | PPO | DPO |
|---|---|---|
| 需要 RM | ✅ | ❌ |
| 模型数量 | 4 | 2 |
| 训练复杂度 | 高（RL，不稳） | 低（监督学习） |
| 显存 | 大 | 小 |
| 数据使用 | on-policy（采新样本） | off-policy（固定偏好集） |
| 效果上限 | 高 | 略低或持平 |

## 6. GRPO：DeepSeek 的简化版 PPO

**GRPO**（Group Relative Policy Optimization）：**去掉 Critic**。

### 6.1 核心改动

不用 critic 估 value，而是**组内归一化**作为 baseline。

**算法**：
1. 对同一 prompt $x$，采样一组答案 $\{y_1, \dots, y_G\}$
2. 用 RM 或规则计算每个奖励 $r_i$
3. 组内归一化作为 advantage：

$$A_i = \frac{r_i - \text{mean}(r_1, \dots, r_G)}{\text{std}(r_1, \dots, r_G)}$$

**符号说明**：
- $G$：组大小（典型 4-16）
- $r_i$：第 $i$ 个答案的奖励
- $A_i$：组内归一化后的 advantage
- $\text{mean}, \text{std}$：组内均值、标准差

4. 用 PPO 风格 clip 更新（advantage 用 $A_i$）
5. 保留 KL 约束

### 6.2 好处

- **省一半显存**（无 Critic）
- 数学/代码任务用 rule-based reward 极简
- 训练更稳定

### 6.3 DeepSeek-R1 的应用

- 用 GRPO 在数学/代码题上做大规模 RL
- 触发"推理涌现"（长 CoT、self-correction）
- R1 系列的核心技术

## 7. 其他对齐方法

| 方法 | 思路 |
|---|---|
| **RLAIF** | 用 AI 生成偏好数据替代人标（Claude） |
| **Constitutional AI** | 模型自我修正 + RLAIF（Anthropic） |
| **ORPO** | SFT + 偏好 loss 一起训，单阶段 |
| **SimPO** | DPO 简化版，去掉 ref 模型 |
| **KTO** | 二元反馈（好/坏）即可，无需 pairwise |
| **Iterative DPO** | 反复"采样 → 标注 → DPO" |

## 8. Reward Hacking

**定义**：策略找到 RM 漏洞，刷高分但实际质量差。

**典型表现**：
- 输出特定格式（如总用 markdown 列表）骗高分
- 偏好长答案（RM 偏向长）
- 重复用某些"奖励关键词"

**对策**：
1. KL 约束（限制偏离 SFT）
2. 多 RM 集成
3. 离线评估（LLM-as-judge 或人评）
4. 持续更新 RM

---

## 9. 对齐税（Alignment Tax）

**定义**：RLHF 后模型在通用 benchmark（如 MMLU）上的下降。

**原因**：
- KL 约束不足，过度优化对齐目标
- 偏好数据集偏向某风格

**缓解**：
- 增强 KL 约束
- RLHF 中混入预训练数据
- 多任务 RM（cover 知识、推理、安全多维度）

---

## 10. 最简记忆

```text
RLHF 三阶段：SFT → RM → RL(PPO)

PPO 目标：max E[r(x,y) - β·KL(π_θ || π_ref)]
  4 模型：Actor / Critic / RM / Reference
  clip 限制单步更新

DPO：从 RLHF 最优解反解 reward → 监督损失
  2 模型：Policy / Reference
  无需 RM

GRPO（DeepSeek）：去 Critic，用组内均值/std 做 baseline
  3 模型：Actor / RM / Reference
  数学/代码用规则奖励极简
```

## 🎯 高频追问

1. **DPO 的 $\beta$ 怎么选**？典型 0.1-0.5。$\beta$ 大 → 约束强、偏好优化弱。

2. **GRPO 的 $G$ 怎么选**？8-16 常见。太小估计噪声大，太大算力开销大。

3. **PPO 不稳定在哪**？RL 高方差 + 4 模型 + on-policy 采样，调参敏感。

4. **DPO 训练时 ref 模型怎么处理**？冻结的 SFT 模型；ref logits 可预计算缓存。

5. **PRM vs ORM**？过程奖励对每步打分（细），结果奖励只看最终答案（粗）。复杂推理倾向 PRM，简单任务 ORM 够。
